# Проверка фактов за 2026-08-19

## Пост 1. Claude-агент вместо ручных договоров, счетов и актов

- Первоисточник: https://vc.ru/ai/3083094-avtomatizatsiya-sozdaniya-dogovorov-i-schetov-s-pomoshchyu-ai-agenta
  — открыт целиком (F-01, путь 1)
- Подтверждение: не требуется отдельно, первоисточник открыт полностью; статья написана автором
  от первого лица о собственном опыте, второй независимой публикации того же случая в природе нет

Факты:
- Автор — Иван Юницкий, речь о его собственной практике (обучающий проект «Точки над ИИ» /
  Tochki Camp), дата публикации 17.08.2026
- Инструмент — Claude (AI-агент на Claude Agent SDK) с собственным skill-ом, который хранится
  в папке `~/.claude/skills/contract/` и представляет собой текстовый файл с шаблонами и
  процедурой
- Раньше на комплект документов (договор, счёт, акт выполненных работ) уходило около получаса
  на клиента; после настройки skill — около минуты на генерацию плюс вычитка
- Настройка skill заняла у автора около 1 часа
- Готовые файлы агент кладёт на рабочий стол в форматах .docx, .xlsx, .pdf
- Skill подставляет данные в готовый шаблон (ИНН, КПП, ОГРН, юридический адрес, банковские
  реквизиты, ФИО руководителя, сумма, номер и дата), а не сочиняет текст документа с нуля —
  автор отдельно подчёркивает, что генерация текста здесь вредна
- Цена/подписка в статье не упоминается

## Пост 2. Навык /design в Claude Code

- Первоисточник: https://vc.ru/ai/3084886-anthropic-dobavila-navyk-design-v-claude-code
  (объявлено 18.08.2026, «вчера» на момент прогона) — открыт целиком (F-01, путь 1)
- Подтверждение: https://support.claude.com/en/articles/14604416-get-started-with-claude-design
  — официальная справка Anthropic, открыта целиком, факты совпадают

Факты:
- Функция Claude Design встроена в Claude Code (CLI и десктоп-приложение) через команду
  `/design`: раньше дизайн-холст жил только в отдельной вкладке claude.ai/design
- Работает как чат слева и холст с макетом справа: можно попросить несколько вариантов
  интерфейса, выбрать понравившийся, дальше попросить Claude написать код — либо, наоборот,
  загрузить существующий код и подобрать под него стиль
- Автоматически подхватывает брендовые цвета, шрифты и компоненты организации, если они заданы
- Доступен подписчикам планов Pro, Max, Team и Enterprise
- Расход считается из общего лимита использования вместе с обычным чатом и Claude Code —
  отдельной квоты на дизайн нет
- Экспорт — .zip, PDF, PPTX, либо передача в Adobe, Canva, Figma, Vercel
- Источники расходятся в статусе функции: vc.ru называет его «исследовательским превью»,
  support.claude.com — «бета». По F-06 этот статус в пост не идёт вовсе, называется только
  список доступных планов

## Пост 3. Блокировка спам-приглашений в Google Calendar

- Первоисточник: https://workspaceupdates.googleblog.com/2026/08/managing-unsolicited-event-invitations-with-user-blocking-in-Google-Calendar.html
  — открыт целиком (F-01, путь 1), официальный анонс Google Workspace, дата 18.08.2026

Факты:
- При блокировке пользователя в Google Calendar текущее приглашение от него автоматически
  удаляется, новые приглашения от этого человека больше не приходят
- Заблокированный попадает в общий список блокировки аккаунта Google, единый для всех
  поддерживаемых продуктов
- Блокировать так можно только отправителей с аккаунтом Google; приглашения от отправителей без
  Google-аккаунта снимаются через блокировку в Gmail
- Доступно всем клиентам Google Workspace и подписчикам Workspace Individual, без ограничений по
  тарифному плану
- Раскатка началась 18.08.2026, растянута до 15 дней и для Rapid Release, и для Scheduled
  Release доменов
- Отдельного администраторского управления для этой функции нет — включает и настраивает
  каждый пользователь сам себе
