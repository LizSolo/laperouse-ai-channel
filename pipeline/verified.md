## Пост 3. Куда девать идеи из сессий с coding-агентом

## Пост 4. Код считает, модель описывает (YADRO)
- Первоисточник: https://habr.com/ru/companies/yadro/articles/1099914/ (открыт целиком, автор Егор Шлюпиков)
- Подтверждение: не требуется — первоисточник открыт целиком (F-01)
- Факты: сервис отчётности в YADRO публикует больше десяти отчётов каждое утро для пяти отделов; все цифры в отчётах считает код, модель только описывает готовые цифры словами — числа физически не проходят через модель, поэтому она не может их искажать; скрипт готовит полный набор данных для шаблона и сжатый набор из нескольких десятков ключевых цифр для модели; модель возвращает текст с заполненными местами, значения туда вставляет код; при недоступности модели или плохом ответе отчёт всё равно публикуется в срок с верными цифрами, просто без комментария (graceful degradation); у части учётных записей оборудования не было цены, недостающие значения восстановили по когортам похожего оборудования и отдельно пометили как оценочные; автор пишет, что так отчёты строятся в несколько раз быстрее, чем через дашборды, при сравнимом качестве; главный вывод автора — то, что модели не дали роль, которую она может сделать ненадёжно (считать), важнее выбора конкретной модели или платформы.
- Числа поста: 10, 5.
