# Проверка фактов за 2026-08-17

## Пост 1. Контур.Фокус — ИИ-анализ договоров

Первоисточник: https://www.cnews.ru/news/line/2026-08-11_konturfokus_predstavil (открыт
целиком через WebFetch, F-01 путь 1)
Подтверждение: https://focus.kontur.ru/site/news/87389-analizirujte_dogovory_v_fokuse_s_pomoshhyu_ii
(официальный анонс сервиса, найден поиском — домен закрыт прокси, факты совпадают дословно)

Факты:
- Сервис «Контур.Фокус» получил функцию ИИ-анализа договоров с контрагентами.
- Договор загружается в формате DOCX/PDF или текстом.
- Проверка идёт по 40+ юридическим и коммерческим рискам (по матрице рисков команды Фокуса).
- Анализ занимает до 10 минут вместо обычного ручного изучения договора.
- Сотрудники, которые работают с договорами контрагентов, тратят на их изучение около 40%
  рабочего времени (данные исследования, на которое ссылается источник).
- Риски делятся на три уровня — высокий, средний, низкий; для каждого риска есть рекомендация,
  как его устранить.
- Перед анализом текст договора анонимизируется: убираются имена людей, названия юрлиц,
  реквизиты и другие персональные данные.
- Цена и тарифные условия функции в источниках не указаны — в посте не упоминаются.
- Дата публикации источника: 11.08.2026, 09:13.

Факты:
- Сервис Vibecraft от Yandex B2B Tech создаёт прототипы сайтов и веб-приложений по текстовому
  описанию задачи, доступен на vibe.sourcecraft.dev.
- Официально запущен 25.06.2026 — обзор от 15.08.2026 вышел про сервис, которому на момент
  публикации почти два месяца.
- Новый пользователь получает 4000 нейрокредитов на тест при регистрации.
- В тесте автора Habr создание сайта автосервиса с онлайн-записью заняло 52 минуты и
  потратило 530 нейрокредитов.
- Основная рабочая среда сервиса требует знания Git и SSH-ключей; без этого, по словам автора
  теста, пользоваться сервисом может в первую очередь профессиональный разработчик.
- Сервис не генерирует изображения и SVG автоматически.
- Монетизация будет на подписке, часть функциональности останется бесплатной.
- Цена и тарифные условия за пределами тестовых нейрокредитов в источниках не указаны — в
  посте не упоминаются.
- Технический стек Vibecraft (какая именно модель лежит в основе) в официальном анонсе и в
  тесте автора расходится — в посте не упоминается (F-06).
