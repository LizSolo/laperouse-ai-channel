## Пост 5. Claude Opus 5 нашёл уязвимость и помог взломать OpenAI в рамках bug bounty

- Первоисточник:
  `https://techcrunch.com/2026/09/18/researchers-used-anthropics-claude-to-hack-into-openai/`
  — открыт целиком (F-01, путь 1).
- Факты:
  - Исследователи: команда из трёх человек стартапа Hacktron AI, участвовавшая в официальной
    программе bug bounty OpenAI.
  - Цепочка уязвимостей: баг в библиотеке `libheif` при обработке HEIF-изображений (формат
    iPhone) в форумном ПО Discourse → ошибка памяти → доступ к серверу → захват аккаунтов
    сотрудников OpenAI в ChatGPT и Codex → доступ к внутреннему GitHub-репозиторию компании.
  - Ключевое сравнение моделей: Claude Opus 4.8 не смог собрать рабочий эксплойт; Claude
    Opus 5 справился в течение часов после своего релиза.
  - Результат: OpenAI выплатила вознаграждение $6500 и закрыла уязвимости к 27 июля 2026.
  - Дата публикации статьи: 18 сентября 2026.
- F-03: названия — Claude, Claude Opus 5, Claude Opus 4.8, OpenAI, Hacktron AI, Discourse,
  ChatGPT, Codex, GitHub — присутствуют выше.
- F-05: сумма вознаграждения $6500 не тарифная цена, а разовая выплата по bug bounty; отдельно
