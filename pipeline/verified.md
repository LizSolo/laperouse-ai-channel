## 1. «Переписка вместо ТЗ»: готовый промпт для ChatGPT

Первоисточник: https://vc.ru/ai/3206348-perepiska-s-klientom-i-chatgpt-kak-sozdat-tekhnicheskoe-zadanie (открыт целиком, F-01: путь 1)
Подтверждение: не требуется, первоисточник открыт целиком.

Факты:
- Автор публикует от блога «РаботAI» (vc.ru), дата публикации — относительная («вчера» на момент прогона 21.10, то есть 20.10.2026), точная дата на странице не выведена в тексте.
- Пример расплывчатой заявки клиента: «Сделайте страницу акции. Как в прошлый раз, только проще. И к пятнице».
- Готовый промпт (цитируется дословно): «Преврати переписку ниже в черновик ТЗ. Выдели: 1. Цель и ожидаемый результат. 2. Что нужно сделать. 3. Требования и ограничения. 4. Сроки и необходимые материалы. 5. Что нужно уточнить у клиента. Отдели подтверждённые факты от предположений. Не придумывай сроки, детали и договорённости. Если данных нет — напиши «не указано». Переписка: [вставь сообщения]».
- Четыре пункта проверки черновика: подтверждённые требования, расплывчатые формулировки («сделайте современно», «как обычно»), сроки (не просто «к пятнице», а точная дата), недостающие материалы.
- Пример сообщения клиенту с уточняющими вопросами приведён в статье.
- Оговорки автора: не просить ChatGPT просто «написать ТЗ» (сам добавит предположения); хранить сообщения по порядку; сверять черновик с оригиналом; не загружать в чат личные данные и закрытую переписку без разрешения, начинать можно с обезличенного примера.
- Статистики, замеров эффективности, процентов в статье нет — всё описание метода, не исследование.

## 4. ChatGPT: блокировка отдельных чатов

Первоисточник: https://techcrunch.com/2026/10/20/chatgpt-now-lets-you-lock-your-chats/ (открыт целиком, F-01: путь 1)
Подтверждение: справочная страница OpenAI, упомянутая в статье — https://help.openai.com/en/articles/20001411-using-locked-chats-in-chatgpt (не открывалась отдельно, цитируется статьёй).

Факты:
- Автор — Aisha Malik, TechCrunch, 20 октября 2026, 11:36 AM PDT. OpenAI объявила о функции во вторник (20.10).
- Защита: четырёхзначный PIN-код либо Face ID/Touch ID на поддерживаемых устройствах.
- Заблокированные чаты переносятся в отдельный раздел «Locked Chats», скрыты из обычной истории, закреплённых чатов и поиска. В отличие от Temporary Chat (пропадает навсегда), к Locked Chats можно вернуться в любой момент.
- Если включена Memory, у Locked Chats отдельная общая память внутри раздела; новые сообщения там не попадают в обычную Memory.
- Что функция НЕ делает (по словам OpenAI): не создаёт end-to-end шифрование и отдельное зашифрованное хранилище; не меняет срок хранения чата; не удаляет то, что модель уже запомнила до блокировки; не меняет настройку «Improve the model for everyone».
- Сброс PIN-кода безвозвратно удаляет все заблокированные чаты, файлы и прочий контент, защищённый прежним PIN.
- Не работает для: Temporary chats, archived chats, group chats, чатов из общей ссылки, чатов с запланированными задачами, чатов с записями встреч. Не доступна в ChatGPT for Healthcare.
- Тарифы: Free, Go, Plus, Pro, Business, Enterprise, Edu. Раскатка началась 20.10, может быть ещё не у всех пользователей.

## 6. Claude Code Review: общая доступность

Первоисточник: https://claude.com/blog/code-review-is-now-generally-available (найден поиском, F-01: путь 2 — факт подтверждён дословно совпадающими деталями в независимых публикациях)
Подтверждение: https://aicatchup.com/news/claude-code-review-general-availability и https://www.neoteo.com/en/anthropic-makes-claude-code-review-generally-available — даты (15.10.2026) и цифры по времени ревью совпадают.

Факты:
- Дата: 15 октября 2026. Claude Code Review вышел из research preview в общую доступность для организаций на тарифах Claude Team и Enterprise.
- В research preview с марта 2026; за это время доля pull request'ов с содержательными комментариями ревью у самой Anthropic выросла с 16% до 54%.
- Время одного ревью сократилось с ~20 минут в превью до 6-10 минут в GA-версии.
- Включает владелец/owner организации: ставит GitHub App Anthropic, выбирает репозитории, дальше ревью идёт автоматически на каждый новый pull request.
- Глубина ревью настраивается на уровне репозитория: Quick, Standard (по умолчанию), Deep.
- Решение о мерже остаётся за человеком — инструмент только оставляет комментарии к pull request.
- Для Enterprise есть кредиты $10 000-$50 000 (сумма зависит от числа активных мест Claude Code), заявку можно подать до 15 января 2027 года.
- Недоступно для организаций с включённым Zero Data Retention и для организаций на HIPAA/CMEK.
