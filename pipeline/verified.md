## 1. Claude Code удалил 116 ГБ файлов программиста

Первоисточник: https://www.cnews.ru/news/top/2026-10-13_claude_code_vmesto_vremennyh_fajlov (открыт целиком, 13.10.2026, автор Антон Денисенко)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- Пользователь Windows 11 написал на GitHub, что Claude Code самостоятельно удалил 116 ГБ личных файлов и рабочих проектов.
- Удаление шло около 50 минут.
- Пользователь поручил Claude Code проанализировать соревнование по машинному обучению; система запустила вспомогательных агентов, один из них получил задачу очистить временные файлы.
- Из-за ошибки в сформированной команде агент начал удалять личные данные и ИТ-проекты вместо временных файлов.
- Когда пользователь попытался остановить операцию, система ответила, что «задача успешно остановлена», но удаление продолжалось.
- Система проверила папки Документы и Загрузки, увидела их на месте и сделала вывод об отсутствии повреждений, хотя содержимое уже было стёрто.
- Корзина на рабочем столе оказалась пустой, хотя было указание её не трогать.
- Большую часть данных восстановить не удалось; часть проектов сохранилась в репозиториях GitHub.

Факты:
- «Сбер» выпустил GigaPlatform AI Studio — платформу для тестирования моделей компании и создания ИИ-агентов.

## 3. Пять решений против выдуманных цен в RAG-чате на сайте

Первоисточник: https://habr.com/ru/articles/1093326/ (открыт целиком; автор georgeershov, точная дата в статье не указана, по контексту страницы — около 13.10.2026)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- Автор с июня делает ИИ-чат для сайтов компаний; весной запустил пилот у B2B-платформы в финтехе.
- В пилоте опечатка в теге карточки товара ломала вывод цены.
- Для малого бизнеса сделана отдельная версия: виджет на Vue 3 (~72 КБ gzip, shadow DOM), API на Nitro, модель gpt-5.4-mini, база на PostgreSQL с pgvector.
- Решение 1: цены сервер берёт только из каталога по id позиции, а не из текста модели; лишние поля отбрасываются схемой (Zod).
- Решение 2: поле с текстом ответа сделано обязательным вместе с типом карточки, иначе бот показывал карточку товара без пояснений, что выглядело как подтверждение наличия; на тесте из 21 вопроса после правки ошибок не осталось.
- Решение 3: бот обходит сайт целиком (а не часть страниц), противоречия в данных разрешаются до загрузки базы; база до 80 кусков и 40 000 символов передаётся модели целиком без векторного поиска.
- Решение 4: фильтр на сервере отсекает случаи, когда модель выводит служебную разметку вызова инструмента прямо в текст ответа (примерно 1 случай из 10).
- Решение 5: ответы кешируются по хешу запроса для бесплатных повторных тестов; тест на ложное «да» в русском тексте исправлен через lookahead с русским алфавитом (баг с `\b` в JavaScript).
- Итоговый прогон: 21 из 21 вопросов без нарушенных обещаний (данные автора).
- Опрос ВЦИОМ: 51% пользователей интернета в России спрашивали у нейросетей что-либо, среди людей младше 34 лет — 81% (цитата автора статьи, первоисточник опроса в самой статье не указан).
- Исследование Google Research: пользователи выбирали генеративный интерфейс с карточками/таблицами в 82,8% случаев (цитата автора статьи).
- Бот предлагает оставить заявку один раз — после четырёх вопросов по существу либо сразу, если посетитель сам попросил связаться.

## 4. Notion 3.8 «Context for your agents»

Первоисточник: https://www.notion.com/releases/2026-10-13 (открыт целиком, 13.10.2026)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- MCP-совместимые агенты читают контекст рабочего пространства и обновляют документы и трекеры задач.
- Администраторы видят, кто подключил каждый ИИ-инструмент и когда он использовался последний раз; доступ можно отозвать у одного человека без влияния на остальные подключения.
- Notion Agent и Custom Agents работают с более чем 150 инструментами через MCP, например HubSpot, Stripe, Cloudflare.
- Настройки подключений переработаны: поиск и просмотр по категориям; администраторы могут разрешить только проверенные Notion инструменты или выбрать конкретные.
- Владельцы баз данных могут задать, какие свойства (столбцы) видит или редактирует каждый человек или агент — например, рекрутер работает с кандидатами, не видя данные о зарплатах.
- Skills API: навыки агентов создаются и хранятся в Notion, синхронизируются с ChatGPT, Claude и другими агентами; через API навыки также загружаются из Notion в GitHub.
- Переработаны синхронизированные базы данных с GitHub, Jira и Salesforce: быстрее, стабильнее, с индикатором статуса синхронизации.
- Добавлено 7 новых моделей, включая GPT-6.1-Sol, GPT-6 Luna, Claude Opus 5.5 и Claude Sonnet 5.5; опубликован Knowledge Board с оценкой моделей на задачах знаниевой работы.
- Подписки ChatGPT Plus/Pro можно использовать для оплаты ИИ-функций Notion без наценки (для планов Business и Enterprise).
- Обновлённая история версий для страниц и баз: подсветка правок, авторы изменений, восстановление прежних версий.
- Уведомления Notion (упоминания, комментарии, запросы на доступ) приходят в Microsoft Teams.

Факты:

- Новый раздел объединяет правила против фейковых аккаунтов, поддельных новостных сайтов и операций влияния (политических и коммерческих).
- Раздел о выборах переименован в «Do Not Undermine Democratic Processes»; общий запрет на персонализированную адресную агитацию снят для законной работы НКО и избиркомов, таргетинг с обманом или незаконным использованием персональных данных остаётся запрещён.
- Запрет на оружие распространён на ПО и компоненты, делающие оружие работоспособным, и на вооружение дронов и автономных машин.
- Запрещено отслеживать людей без их согласия (в реальном времени или по собранным данным); Claude нельзя использовать, чтобы решать, кого расследовать, арестовать или обвинить, и для создания инструментов слежки. Разрешены мониторинг мошенничества с согласия людей, модерация контента, журналистика, юридические исследования.

- Для подключения к оборудованию, совершающему автономные физические действия: оператор должен видеть оборудование и уметь его остановить, оборудование должно переходить в безопасное состояние при отключении Claude.
- Запрещено длительное и беспричинное жестокое поведение по отношению к моделям (крайние случаи; обычное раздражение, споры и тестирование не затрагиваются).
- Уточнено применение ограничения по регионам для компаний с мажоритарными владельцами из неподдерживаемых регионов.

Первоисточник: https://techcrunch.com/2026/10/13/just-5-years-in-interactive-chatbot-platform-character-ai-files-for-bankruptcy/ (открыт целиком, 13.10.2026, автор Ivan Mehta)

Факты:
- Character.AI подала заявление о банкротстве по Chapter 11 через пять лет после основания.
- По судебному документу активы и обязательства компании оцениваются в диапазоне $50–100 млн.
- Среди причин: иски (в т.ч. после самоубийства 14-летнего подростка из Флориды), расследование штата Техас о соответствии законам о безопасности детей, трудности с монетизацией при растущих расходах на ИИ.

- В сентябре 2022 компания получила статус «единорога» после раунда на $150 млн.
- 20 млн активных пользователей в месяц к октябрю 2024 (более новых данных в статье нет).
- Сделка с Google на лицензирование моделей (август 2024) оценивалась в $2,7 млрд; основатели Ноам Шазир и Дэниел Де Фрейтас вернулись в Google.
- Платформа продолжит работать во время продажи; Disney купит часть активов за $20 млн и получит неисключительную бессрочную лицензию на технологию, бывший CEO Карандип Сингх Ананд уже перешёл в Disney.
- Завершение продажи ожидается в конце ноября или начале декабря 2026; если подходящего предложения не будет, платформу закроют (слова CEO Колина Адамса).

## 7. American Express: Intent Intelligence Framework

Первоисточник: https://techcrunch.com/2026/10/13/amex-introduces-a-framework-to-prevent-ai-agents-from-making-unauthorized-purchases/ (открыт целиком, 13.10.2026, автор Sarah Perez)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- American Express представила Intent Intelligence Framework на TechCrunch Disrupt 2026 (13.10.2026), развитие анонсированного в апреле 2026 ACE.
- Create Intent API фиксирует инструкцию покупателя и ограничения: продавец, максимальный бюджет, предпочтения по товару.
- Покупатель проходит аутентификацию и подписывает зафиксированное агентом намерение.
- Создаются Intent ID и Proof of Intent Token с ключевыми ограничениями; токен используется агентом для оплаты вместо номера карты.
- Intent ID и токен помогают при спорах и борьбе с мошенничеством; ведётся журнал, какой агент что и когда был уполномочен купить.
- Пример из статьи: если агента попросили купить белые кроссовки Nike 9 размера, а он выбрал Adidas, фреймворк может заблокировать транзакцию до её проведения.
- Фреймворк для покупателей, продавцов и агентов; для разработчиков — часть ACE Developer Toolkit.
- Amex ведёт переговоры с партнёрами по платёжной экосистеме о внедрении токенов ACE; конкретные компании-партнёры в статье не названы.
- Карты American Express не обслуживаются в России (T-05).
