## 1. «Гравител»: автообзвон на нейросети

Первоисточник: https://www.cnews.ru/news/line/2026-10-12_do_10_tysyach_zvonkov_v_chas (открыт целиком, 12.10.2026)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- Компания «Гравител» внедрила предиктивный автообзвон на нейросетях для холодных исходящих звонков.
- До 10 тысяч звонков в час, до 1 тысячи линий одновременно, работа круглосуточно без выходных.
- Распознавание русской речи с точностью до 98%.
- По данным «Гравител», 20-30% абонентов в типовой базе системно не отвечают на холодные вызовы.
- Робот понимает смысл фразы (не ключевые слова), отвечает на типовые возражения («дорого», «неинтересно»), формирует реплики через GPT.
- Заинтересованного клиента соединяет с живым менеджером прямо во время разговора.
- Итоги звонков (статус, запись, результат) автоматически попадают в CRM.
- Готовые интеграционные модули для «Битрикс24», amoCRM и 1С; для прочих систем — открытый API.
- Цена в статье не указана.

## 2. Сметчик на ИИ: ошибка на 515 786 рублей

Первоисточник: https://habr.com/ru/articles/1093050/ (открыт целиком, датирован 12.10.2026 по дайджесту «Ежедневный Хабр»)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- Автор (Habr, OstapAndreevich) сделал «ИИ-сметчика» для московской компании по ремонту квартир.
- Система проверила пять рабочих смет, выдала 310 замечаний в прогонах 16-21.08.2026.
- Итог одной смете был занижен на 515 786 ₽: 212 661 ₽ (формула ссылалась на шапку, а не на итог этапа) + 237 500 ₽ (диапазон не захватил строку инженерной доски) + 65 625 ₽ (диапазон не захватил строку плинтусов).
- Ошибку нашли при обследовании смет вручную, до разработки системы; правило для её автоматического выявления написали потом.
- Все числовые расчёты и проверки делает детерминированный код, а не нейросеть; нейросеть используется только для чтения документов и общения с заказчиком.
- Промпт-правило на стенде нарушалось примерно 1 раз из 8 прогонов — поэтому автор не доверяет финальный расчёт модели.
- Точность системы: из 177 замечаний, сверенных автором, 51 подтвердился, 99 спорных, 27 ложных (≈8,7% от 310). Полнота по эталонному списку из 75 пунктов — 69 (92%) на обучающих данных, 85,3% на контрольном наборе (автор называет результат предварительным).

## 3. Claude Sonnet 4.5: вывод из эксплуатации 30.11.2026

Первоисточник: https://platform.claude.com/docs/en/about-claude/model-deprecations (открыт целиком)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- 30 сентября 2026 Anthropic уведомила разработчиков об отключении модели Claude Sonnet 4.5 (claude-sonnet-4-5-20250929) в Claude API.
- Дата отключения (retirement): 30 ноября 2026.
- Рекомендованная замена: claude-sonnet-5-5 (в тексте документации также называется Sonnet 5.5).
- После даты отключения запросы к модели claude-sonnet-4-5-20250929 будут завершаться ошибкой («Requests to retired models will fail»).
- Anthropic даёт минимум 60 дней уведомления перед отключением публично выпущенных моделей.
- Проверить использование устаревших моделей можно через страницу Usage в Claude Console (Export → CSV с разбивкой по ключу API и модели).
- Даты относятся к Anthropic-платформам (Claude API, AWS Claude Platform, Microsoft Foundry); у партнёрских платформ (Amazon Bedrock, Google Cloud) свои сроки отключения.

## 4. Google: агентный режим Gemini для бизнеса

Первоисточник: https://techcrunch.com/2026/10/08/google-brings-agentic-ai-to-gemini-starting-with-businesses/ (открыт целиком, 08.10.2026, автор Sarah Perez)
Подтверждение: не требуется — первоисточник открыт полностью (F-01)

Факты:
- Google представил единый агентный режим Gemini: агенту ставят цель («objectives, not just instructions»), а не инструкцию по шагам.
- Агент сам планирует работу, использует навыки и инструменты пользователя, подключается к внутренним системам компании.
- По умолчанию агент сам выбирает модель под задачу; пользователь может выбрать модель вручную, включая сторонние — первой добавлена Claude от Anthropic.
- Интеграции: Google Workspace, Microsoft 365, Slack, Jira, Confluence, Git, BigQuery, Databricks, Postgres, Snowflake и подключение к любым MCP-серверам внутри и вне сети компании.
- «Tasks inbox» — интерфейс, где видно, что делает агент: ход рассуждений, делегирование подагентам, загрузку навыков, код, прогресс.
- Запуск сначала для бизнеса, потребительский запуск позже. У агента свой аккаунт Workspace с email, его действия идут в журнал аудита от имени агента.
- Доступ с iOS, Android, Windows, Mac, командной строки, Google Workspace, Microsoft 365, ServiceNow, Slack.
- Ранние тестировщики: On, Shopify, PayPal.
- Цена/тариф в статье не указаны (упомянуты только гибкие схемы оплаты без цифр).
