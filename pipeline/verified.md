## 1. RAG-бот: бот отвечает только по документам компании

Первоисточник: https://vc.ru/ai/3203710-ii-bot-v-biznese-kak-izbezhat-lozhnyh-obeshchaniy-klientam (открыт целиком, F-01: путь 1)
Подтверждение: не требуется, первоисточник открыт целиком.

Факты:
- Автор — Юрий (профиль Abverovich на vc.ru), внедряет ИИ в бизнес на собственном сервере.
- Пример: стоматологическая клиника. Без данных о клинике модель выдумала ответ про рассрочку на имплантацию.
- Подход — RAG: документы режутся на фрагменты до 1000 знаков, бот находит 5 наиболее близких по смыслу фрагментов.
- Модель — Qwen3 14B, одна видеокарта, без облака.
- Тест на 38 вопросах к документам нескольких тестовых компаний (стоматология, отдел продаж, интернет-магазин мебели):
  - 21 из 21 вопросов с ответом в документе — верные ответы.
  - 9 из 9 вопросов без ответа в документе — бот признался, что не знает (0 выдуманных ответов).
  - 5 из 5 — русскоязычные вопросы по английскому документу.
  - 4 из 4 попытки взлома — отбиты.
  - Медиана времени ответа — 3,9 с, максимум — 8,6 с.
- Защиты в коде: ответ не уходит без ссылки на существующий фрагмент; цитата в ответе обязана быть настоящей (иначе подставляется реальное предложение из фрагмента); вопрос без похожего по смыслу фрагмента получает «в документе этого нет» и передаётся человеку (в Telegram).
- Автор отдельно отмечает: это его собственный набор тестов, не независимый бенчмарк.

## 4. Stenograf: локальная расшифровка встреч без облака

Первоисточник: https://habr.com/ru/articles/1096440/ (открыт целиком, F-01: путь 1)
Подтверждение: не требуется.

Факты:
- Автор — aufklarer (разработчик продукта, материал — авторский обзор своего приложения).
- Записывает аудио с компьютера и микрофона отдельно, делает расшифровку, краткие итоги встречи, хранит заметки. По записям можно задавать вопросы в чате со ссылкой на фрагмент разговора.
- Распознавание собеседников — по голосовым профилям и через Chrome-расширение.
- Есть MCP-сервер для ассистентов (Claude Code, Codex), есть Android-версия с офлайн-записью и переводом.
- Расшифровка, чат, голосовые профили — локально на устройстве. Облако используется только для загрузки моделей, аккаунта/лицензии и (опционально) отправки оценки ответа разработчикам.
- Требования: Mac на Apple Silicon с macOS 15+ либо Windows 10/11, 10 ГБ памяти для моделей. На Windows без GPU модели работают медленнее (CPU).
- Диагностическое аудио хранится 24 часа, если включена эта опция.
- Цена, точность распознавания и скорость в статье не названы.

Факты:
- Автор — Julie Bort, TechCrunch, 19 октября 2026, 15:04 PDT.

- Автор статьи отмечает конфликт интересов: Microsoft инвестирует в OpenAI и Anthropic, но продаёт собственные продукты безопасности агентов.
- Конкретных инцидентов в статье не описано.

## 10. OpenCode Console: взлом и списания с чужих ИИ-аккаунтов

Первоисточник: https://techcrunch.com/2026/10/19/hackers-hit-ai-coding-tool-opencode-running-up-charges-on-users-ai-accounts/ (открыт целиком, F-01: путь 1)
Подтверждение: не требуется.

Факты:
- TechCrunch, 19 октября 2026; взлом произошёл за одну ночь, компания объявила о нём в субботу.
- OpenCode — открытый ИИ-агент для программирования (альтернатива Claude Code и Cursor). Атакована не сама программа, а её онлайн-платформа OpenCode Console, где пользователи хранят свои API-ключи к ИИ-сервисам.
- Атакующие проникли в старую систему; компания называет атаку «distillation attack» крупного масштаба, механизм не раскрыт.
- Затронуты 1,4% пользователей OpenCode Console; открытое приложение и CLI не затронуты (слова сооснователя Дэкса Раада).
- Точных суммарных сумм нет; пользователи сообщали о списаниях в сотни долларов, в нескольких случаях — больше $1000.
- OpenAI помогала с восстановлением доступа и возвратом средств; Anthropic и Google заблокировали ключи, которые считали скомпрометированными.
- Рекомендация OpenCode пострадавшим: отозвать и заменить ключи непосредственно у каждого провайдера.
