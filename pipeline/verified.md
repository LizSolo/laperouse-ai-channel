- Подтверждение (не обязательно по F-01, но совпадает дословно): https://www.sostav.ru/publication/rossijskij-biznes-kratno-uvelichil-ispolzovanie-zarubezhnykh-bolshikh-yazykovykh-modelej-86053.html

Факты:
- Дата публикации первоисточника: 13.08.2026
- Источник данных внутри статьи: MWS Cloud (МТС Web Services), платформы MWS GPT Model Hub и MWS GPT
- Потребление китайских LLM российским бизнесом в 1 полугодии 2026: свыше 400 млрд токенов

- Kimi — 81,4 млрд токенов

- Каталог MWS GPT Model Hub расширен почти вдвое, до 17 моделей: добавлены GLM 5.2, Kimi K2.6,
  Qwen 3.6, Gemma 4, GPT OSS, плюс модели распознавания/синтеза речи и reranker для RAG
- Причины роста по данным статьи: доступная цена, открытость моделей (open source), возможность
  разворачивать на российской инфраструктуре

## 2. AI Guard — расширение для Chrome, маскирует данные при отправке в ИИ-чат

- Первоисточник: https://habr.com/ru/articles/1071398/ (открыт напрямую, F-01 путь 1)
- Подтверждение: не требуется по F-01 (первоисточник открыт целиком); второй публикации с тем же
  предметом не нашлось — сервис новый и специализированный.

Факты:
- Дата публикации: 16.08.2026
- Название: AI Guard, расширение для браузера Chrome, доступно в Chrome Web Store
- Механизм: расширение перехватывает отправку текста в ИИ-чат и меняет чувствительные значения на
  псевдонимы вида `[card_348zsg]`; на сервер ИИ уходит замаскированный текст, а расширение
  автоматически расшифровывает ответ обратно на экране пользователя
- Словарь соответствий «оригинал → псевдоним» хранится только в памяти браузера и стирается вместе
  с ней
- Защищает 33 категории данных: российские ИНН, СНИЛС, ОГРН, номера карт (с проверкой
  контрольных сумм), ФИО в разных падежах, API-ключи, пароли; отдельно — обработка файлов и
  сканов документов через локальный OCR
- Есть режим «Показать псевдонимы» — показывает, что физически ушло на сервер, без расшифровки
- Целевая аудитория по тексту статьи: HR-специалисты, юристы, бухгалтеры, IT-специалисты и любые
  сотрудники, использующие ИИ-чаты в работе
- Версии: бесплатная (текстовая защита, базовые правила) и платная с расширенными функциями по
  запросу

- Первоисточник: https://venturebeat.com/orchestration/spacexais-grok-bot-turns-agents-into-persistent-digital-coworkers-that-can-operate-your-apps-for-120-per-month

- Подтверждение: https://www.arturmarkus.com/spacexai-launches-grok-bot-on-august-11-persistent-ai-agents-run-on-dedicated-cloud-vms-at-120-month-per-seat/
  (совпадает дословно: дата запуска 11 августа, цена $120/мес за место, выделенные cloud VM)

Факты:
- Запуск: бета, 11 августа 2026
- Компания: SpaceXAI (ранее xAI)
- Механизм: пользователь создаёт постоянного «Бота» с конкретной задачей, даёт ему доступ к
  приложениям и сайтам; дальше бот работает сам, продолжает работу даже при закрытом ноутбуке
  пользователя, возвращается за подтверждением или с готовым результатом
- У каждого бота — собственная компьютерная среда (выделенная cloud VM); может входить в сервисы,
  учиться по демонстрации и передавать задачи другим ботам

- Доступ на дату проверки: лист ожидания для новых организаций
- Оплата из России: прямая оплата российской картой не проходит — Stripe отклоняет карты
  российских банков-эмитентов, нужен сервис-посредник. Источник отдельного факта:
  https://habr.com/ru/companies/Exnode/articles/1062596/ («Купить подписку Grok из России в 2026
  году»), открыт напрямую
