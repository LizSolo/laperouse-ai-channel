## Пост 4. Как платить за DeepSeek API из России

- Первоисточник 1: https://vc.ru/ai/3233420-oplata-deepseek-api-iz-rossii (vc.ru, опубликовано 03.11.2026 «вчера», текст рекламный — партнёрская карта «Хочу Плачу!»)
- Первоисточник 2 (независимое подтверждение и альтернативный способ): https://habr.com/ru/articles/1103326/ (Хабр, автор @redlse, опубликовано ок. 04.11.2026)
- Подтверждение: оба источника открыты целиком через WebFetch (F-01, путь 1 для каждого; используются как два независимых независимых способа оплаты одной темы)
- Факты:
  - Ключ DeepSeek API бесплатный, но списание идёт с предоплаченного баланса; без баланса запрос возвращает ошибку 402 Insufficient Balance
  - По справке DeepSeek, способы оплаты: PayPal, банковские карты, Alipay, WeChat Pay; рублей и СБП нет
  - Способ 1 (vc.ru): завести карту для зарубежных платежей (в статье — карта «Хочу Плачу!», пополняется рублями через СБП), и оплатить DeepSeek прямо на странице Top Up банковской картой
  - Цены за 1 млн токенов вне пика: deepseek-flash — вход $0,15, вход из кэша $0,003, выход $0,60; deepseek-v4-pro — вход $0,66, вход из кэша $0,022, выход $1,98
  - Пиковые часы (цена вдвое выше): будни, 01:00–04:00 и 06:00–10:00 UTC, то есть 04:00–07:00 и 09:00–13:00 по Москве; выходные и китайские государственные праздники — целиком по сниженной цене
  - Способ 2 (habr.com): завести кошелёк Alipay по российскому номеру телефона, верифицировать загранпаспортом РФ (у автора заняло 2–3 часа), перевести деньги через приложение Сбербанка (перевод за границу → Китай → по номеру телефона) и оплатить в DeepSeek через QR-код Alipay
  - У автора habr.com перевод 5000 рублей дал 382 юаня (примерно 13,09 рубля за юань на дату операции); это пример суммы, а не минимальный порог
  - Привязать карту РФ напрямую к Alipay нельзя (на дату публикации)
  - Ключ API нельзя передавать третьим лицам и вставлять в браузерный код; при утечке — отозвать на странице API Keys

  - Вайбкодинг: человек описывает задачу словами, ИИ-агент генерирует и запускает код, человек проверяет результат и уточняет запрос
  - Инструмент — Битрикс24 Вайбкод (vibecode.bitrix24.tech): платформа для приложений и чат-ботов на базе Битрикс24, вход через существующий аккаунт без отдельной регистрации

  - Приложения размещаются на серверах «Black Hole» (не видны напрямую из интернета), права доступа гибкие (лично, отдел, вся компания, по ссылке), неиспользуемый сервер «засыпает»

  - Готовые шаблоны: классификатор обращений, описания товаров, скоринг лидов, HR-бот, чат-бот по базе знаний
  - Задачи, которые статья не рекомендует доверять ИИ без специалиста: платежи, персональные данные, финансовые расчёты, медицина, высокие нагрузки

  - Кейс 2 (Татьяна Мазаева, рекрутер Битрикс24): три инструмента — выделение релевантного опыта в резюме, персонализированные письма кандидатам, первичная оценка софт-скиллов; время на первичный отбор сократилось до 4–6 часов, освободилось 15–20 часов в неделю, решение по кандидатам остаётся за рекрутером
