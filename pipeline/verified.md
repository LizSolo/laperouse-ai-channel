## Тема 2. Gemini: агентное понимание видео

URL первоисточника: https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-agentic-video-in-gemini/
URL подтверждения: не требуется — первоисточник открыт целиком через WebFetch (F-01, путь 1)

Факты:
- Название функции: agentic video understanding
- Суть: модель сама решает, какие фрагменты видео разбирать и с какой частотой кадров, вместо
  обработки всего видео с фиксированной частотой; использует три модальности — кадры, аудио,
  транскрипт
- Снижение расхода токенов: до 88% с моделью Gemini 3.7 Flash
- Рост точности: до 7% с той же моделью
- Снижение расходов: до 66%
- Модели, к которым применяется: Gemini 3.7 Flash, 3.6 Flash, 3.5 Flash-Lite
- Доступность: Gemini API (Google AI Studio и Gemini Enterprise Agent Platform), работает с
  загруженными видео и видео с YouTube; по стандартным ценам токенов Gemini API, без доплаты
  за саму функцию; в приложении Gemini для всех пользователей — скоро; будет интегрировано в
  Ask YouTube
- Дата публикации: 1 сентября 2026

## Тема 3. Anthropic: Claude Commerce Agents (шаблоны торговых ИИ-агентов)

URL первоисточника: https://claude.com/blog/claude-for-commerce-agents (домен closed allowlist,
не открылся)
URL подтверждения: https://github.com/anthropics/commerce-agents (открыт целиком через
WebFetch напрямую — F-01, путь 1 по репозиторию; плюс перекрёстно через WebSearch совпадают
цифры и факты в MarkTechPost, digitalcommerce360.com, KuCoin, startupfortune.com — F-01, путь 2
для цифр результата пилотов)

Факты:
- Название: Claude Commerce Agents — открытый reference blueprint от Anthropic
- Дата публикации: 2 сентября 2026
- Состав: два агента — Shopping Agent (для покупателей: поиск товаров, сравнение, сборка
  корзины, чекаут, вопросы поддержки) и Merchant Agent (для продавцов: аналитика продаж, учёт
  остатков, рекомендации по ценам и рекламным кампаниям)
- Вертикали с готовыми примерами: retail, travel, telecom, entertainment
- Результаты пилотов у розничных продавцов (по данным Anthropic): рост наполнения корзины до
  35%, рост вероятности завершения покупки на 60%
- Лицензия: Apache License 2.0, репозиторий не поддерживается автором и не принимает контрибьюции
- Требования: Python 3.11+, Node.js 22+
- Способы запуска: Messages API, Claude Agent SDK, Managed Agents; плагин для Claude Code
  (`claude plugin install commerce-builder@claude-commerce-agents`)
- Платформы развёртывания: Claude API, Amazon Bedrock, Microsoft Foundry, Google Cloud Vertex AI
- Ранние пользователи по данным вторичных источников: Shopify, Visa, Mastercard, Accenture

## Тема 4. Data Sapience: предиктивная аналитика для насоса на НПЗ

URL первоисточника: https://habr.com/ru/companies/datasapience/articles/1078104/
URL подтверждения: не требуется — первоисточник открыт целиком через WebFetch (F-01, путь 1)

Факты:
- Компания-вендор: Data Sapience, платформа Industrial Ocean
- Клиент: нефтеперерабатывающий завод, задача — центробежный насос, который отказывал
  каждые 3 месяца, простой стоил миллионы рублей в час
- Метод: модель обучена на данных с 21 датчика вокруг насоса и на 650 млн исторических точек
  за период нормальной работы, выявляет отклонения (методы вроде градиентного бустинга) и
  показывает вклад каждого датчика в аномалию — интерпретируемо, без знаний data science у
  оператора
- Результаты: упреждение отказа за 60 дней, сокращение времени подготовки к ремонту на 70%,
  исключён простой установки, снижение затрат на актив на 15-20%
- Масштаб: платформа рассчитана на мониторинг 50+ единиц оборудования
- Ограничение: извлечение и подготовка данных занимают до 80% времени проекта; для обучения
  модели нужен data scientist на стороне вендора, а оператор работает с готовыми алертами через
  веб-интерфейс
- Дата публикации: 3 сентября 2026 (в пределах 72 часов от прогона)
