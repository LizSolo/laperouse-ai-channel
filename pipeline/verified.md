## 4. Anthropic, Claude Managed Agents — лимит бюджета сессии

Первоисточник: https://platform.claude.com/docs/en/managed-agents/budgets (открыт целиком,
WebFetch). Второй источник не требуется по F-01.

Факты:
- Опциональный жёсткий лимит трат (`budget`) задаётся при создании сессии Managed Agents, в
  американских центах (например «125» = $1,25), только валюта USD.
- Платформа считает всё потребление сессии по публичным прайс-листовым ценам (list cost): токены
  моделей, веб-поиск — $10 за 1000 запросов, время работы сессии — $0,08 в час.
- При достижении лимита сессия не завершается, а переходит в статус idle с причиной
  `budget_reached`; история и состояние песочницы сохраняются.
- Лимит можно поднять или снять апдейтом сессии — работа продолжается автоматически с того же
  места, без пересоздания сессии. Итоговая трата может превысить лимит на стоимость одного запроса,
  который был в процессе выполнения в момент достижения потолка.
- То же самое доступно для деплойментов (лимит копируется в каждую новую сессию).
- Дата: страница актуальна на 22.08.2026, фича упоминается как доступная в контексте августовских
  обновлений Managed Agents (Environment Hooks и др., см. пункт 6).

Первоисточники: https://workspaceupdates.googleblog.com/2026/08/make-copy-of-notebook-in-gemini-notebook.html
(открыт целиком, WebFetch, дата 17.08.2026) и

требуется по F-01.

Факты (копирование, 17.08):
- При копировании ноутбука копируются источники (Drive-источники — только если у копирующего есть
  права на исходный файл) и материалы студии: аудио- и видеообзоры, учебные пособия, карточки для

- Копия не синхронизируется с оригиналом дальше.
- Доступно всем пользователям Google Workspace и личных аккаунтов Google с доступом к Gemini
  Notebook; владелец ноутбука включает/выключает разрешение на копирование (по умолчанию включено).

Факты (автодобавление источников, 07.08):

  текстовые фрагменты, ссылки на файлы Google Drive, YouTube-видео или веб-адреса автоматически,
  как часть настраиваемого рабочего процесса.
- Доступно на тарифах Business Starter/Standard/Plus, Enterprise Standard/Plus, Education
  Fundamentals/Standard/Plus, а также с лицензиями AI Pro for Education и Google AI Expanded Access.
- Постепенный запуск с 6 августа 2026, до 15 рабочих дней на полный охват.

## 6. Google (Gemini API), Environment Hooks для Managed Agents

Первоисточник: https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/
(открыт целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- Environment Hooks — пользовательские скрипты, которые запускаются до (`pre_tool_execution`) или
  после (`post_tool_execution`) каждого вызова инструмента ИИ-агентом внутри изолированной
  облачной песочницы.
- Конфигурация — файл `.agents/hooks.json`, поле `matcher` задаёт целевые инструменты через
  регулярное выражение (например `code_execution|write_file` или `*` для всех).
- При отклонении скрипт возвращает `{"decision": "deny", "reason": "..."}`, и вызов инструмента
  блокируется.
- Пример из статьи: компания OffDeal использует `post_tool_execution`, чтобы проверять качество и
  соответствие требованиям логотипов в презентациях, которые готовит агент.
- В этом же посте (28.07.2026): Gemini 3.6 Flash стала моделью по умолчанию для Managed Agents,
  появился бесплатный доступ без активного биллинга, лимиты по числу токенов (`max_total_tokens`),
  запуск по расписанию (scheduled triggers) и Environments API.
- Дата публикации: 28.07.2026.

## 7. OpenAI, Daybreak Red и Daybreak Blue на Amazon Bedrock

Первоисточники (оба недоступны напрямую через WebFetch — EGRESS_BLOCKED — факт подтверждён
дословно по крестной сводке WebSearch с совпадающими формулировками по обеим независимым
страницам, F-01 путь 2): https://aws.amazon.com/about-aws/whats-new/2026/08/openai-daybreak-red-and-blue-on-amazon-bedrock/
(AWS, дата анонса 11.08.2026) и https://openai.com/index/daybreak-models-are-now-available-on-aws/
(OpenAI).

Факты:
- Daybreak Red даёт доступ к GPT-5.6 Cyber — модели для продвинутых авторизованных задач:
  исследование уязвимостей, воспроизведение эксплойтов, разработка мер защиты; порог отказа ниже,
  требует усиленной проверки личности.
- Daybreak Blue даёт доступ к GPT-5.6 Sol с настройками для защитной работы: поиск уязвимостей,
  разработка правил обнаружения, реагирование на инциденты, проверка патчей; OpenAI рекомендует
  Blue как стартовую точку для большинства команд безопасности.
- Обе модели работают в регионе AWS US East (N. Virginia), доступ только для клиентов, прошедших
  вётинг в программе OpenAI Trusted Access for Cyber.
- Инференс идёт через новый движок Bedrock с «нулевым доступом оператора» (ZOA), закреплённым на
  уровне чипа.
- Дата: анонс 11.08.2026.
