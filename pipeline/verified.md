# Проверка фактов за 2026-10-02

## Пост 1. Русский текст в Claude Opus 5 дороже, чем в GPT-5.5

- Первоисточник: https://habr.com/ru/articles/1089148/ (открыт целиком, WebFetch)
- Подтверждение: https://www.braintools.ru/article/36359 (та же цифра 3,9 раза и те же цены за 1000 символов)
- Факты:
  - Дата публикации: 27.09.2026, автор donseo
  - При одинаковой цене за токен обработка русского текста на Claude Opus 5 обходится в 3,9 раза дороже, чем на GPT-5.5
  - Claude Opus 5: 0,5318 ₽ за 1000 символов русского текста (медиана по агрегаторам), округлённо — 0,53 ₽
  - GPT-5.5: 0,1377 ₽ за 1000 символов русского текста (медиана по агрегаторам), округлённо — 0,14 ₽
  - Claude Opus 5 укладывает русский текст в среднем 1,03 символа на токен, GPT-5.5 — 4,01 символа на токен
  - На английском тексте разница меньше: 0,1690 ₽ (Claude Opus 5) против 0,1089 ₽ (GPT-5.5), то есть 1,55 раза
  - Причина — разные токенизаторы: Claude Opus 5 режет русский текст почти по буквам
  - Сравнивались 11 моделей, включая YandexGPT, GigaChat, DeepSeek, Gemini, Qwen
  - Вывод автора: сравнивать модели по цене за 1000 символов, а не по цене за токен; держать служебную часть промпта на английском

## Пост 2. Yandex AI Studio: публикация ИИ-агентов в мессенджерах

- Первоисточник: https://yandex.cloud/ru/blog/ai-agents-messengers (открыт целиком, WebFetch)
- Подтверждение: https://www.cnews.ru/news/line/2026-09-22_yandex_b2b_tech_integrirovala_ii-agentov (та же дата и функциональность, независимая публикация)
- Факты:
  - Дата публикации: 22.09.2026
  - Yandex AI Studio позволяет опубликовать готового ИИ-агента в Telegram, Яндекс Телемосте (мессенджере) и MAX за пару кликов
  - Для подключения достаточно указать токен бота на платформе
  - Агенту доступны все возможности сервиса: выбор модели, поиск в интернете и по базам знаний компании, интеграция с внешними сервисами
  - Указанные сценарии использования: поддержка клиентов, консультации по продукту, передача сложных вопросов специалисту, адаптация сотрудников, поиск по внутренним документам
  - Агент также доступен как веб-виджет на сайте
  - Пример: ВШЭ подключила Telegram-бота для студентов на этой технологии, настройка заняла около 20 минут без участия разработчиков
