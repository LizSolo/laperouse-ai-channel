# Проверка фактов за 2026-08-24

## 1. Т2, ИИ-витрина «Элюмента»

Первоисточник: https://www.cnews.ru/news/line/2026-08-13_t2_zapuskaet_edinoe_okno (открыт
целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- Оператор Т2 запустил сервис «Элюмента» — единое окно доступа более чем к 50 нейросетям для
  своих абонентов.
- Поимённо названные модели: GPT-5, Claude, Gemini, Grok, Midjourney, GPT-Image 2, Veo 3.1,
  Nano Banana.
- Регистрация — по номеру телефона Т2, без отдельной привязки банковской карты.
- Оплата списывается с баланса мобильного номера.
- Первые три дня доступа — бесплатно и безлимитно.
- Новый пользователь получает 50 бесплатных токенов; в статье приведён пример: этого хватает
  примерно на 50 изображений или 10 треков.
- Доступны четыре тарифа (от «Базового» до «Максимума»), точные цены и токены по тарифам в
  источнике не названы — в посте эти цифры не используются (F-06).
- Дата публикации: 13.08.2026.

## 2. BSS, «Речевая аналитика» 2.15

Первоисточник: https://www.cnews.ru/news/line/2026-08-10_bss_perevela_rechevuyu_analitiku
(открыт целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- Компания BSS выпустила версию 2.15 продукта «Речевая аналитика» — обновление переводит
  встроенный ИИ из режима реактивной обработки запросов в автономного агента.
- Агент работает по расписанию, без постоянного участия пользователя: сам анализирует записи
  коммуникаций, находит паттерны и аномалии, формирует инсайты и рассылает отчёты
  заинтересованным лицам и смежным подразделениям.
- В основе — технология RAG (Retrieval-Augmented Generation): семантический контроль качества
  на базе корпоративных баз знаний компании без сложной интеграции.
- Целевая аудитория: контактные центры и компании с отделами контроля качества клиентского
  сервиса.
- Дополнительно в версии 2.15: обновлённый UX/UI, расширенные возможности агента-тренера,
  новые инструменты визуализации данных.
- Дата публикации: 10.08.2026.
