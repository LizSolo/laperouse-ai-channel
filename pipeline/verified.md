## Пост 1. Cloudflare: раздельный доступ для поискового и обучающего ИИ-бота

- Первоисточник: `https://habr.com/ru/news/1083142/` — открыт целиком (F-01, путь 1).
- Подтверждение (перекрёстно, F-01 путь 2, потому что blog.cloudflare.com закрыт egress-прокси):
  `https://www.helpnetsecurity.com/2026/07/02/cloudflare-ai-crawler-controls/`,
  `https://www.resultsense.com/news/2026-09-16-cloudflare-disallow-ai-training/`,
  `https://www.financialcontent.com/article/bizwire-2026-9-15-cloudflare-helps-end-the-search-or-ai-training-tradeoff`.
- Факты:
  - Компания: Cloudflare.
  - Новый статус для краулеров — Accountable: обязателен опт-аут от обучения, возможность
    отказаться от ИИ-саммари, видимость на уровне URL, какие страницы отдавались на обучение,
    гарантия, что отказ от обучения не влияет на позиции в обычном поиске.
  - Новая настройка Disallow AI Training: сайт может запретить обучающим краулерам доступ,
    оставаясь полностью в поисковой выдаче.
  - С 15 сентября 2026 для новых доменов меняются настройки по умолчанию: Training- и
    Agent-краулеры блокируются по умолчанию на страницах с рекламой, Search-краулеры остаются
    разрешены по умолчанию.
  - Данные Cloudflare (пересказ habr): 17% владельцев сайтов хотят закрыться от обучающих ботов
    против менее 1% — от поисковых.
  - Google и Apple уже соответствуют критерию Accountable, Microsoft обещает поддержку в начале
    2027 года.
  - Cloudflare покрывает более 20% всех сайтов в мире.
- F-05: цены нет, функция бесплатная настройка в панели Cloudflare.
- F-06: цифра 17%/1% — из одного источника (Cloudflare, пересказ habr), расхождений с другими
  источниками не найдено, оставлена.

## Пост 2. Kalypta: приложение против расшифровки созвонов нейросетями

- Первоисточник: `https://habr.com/ru/news/1083160/` — открыт целиком (F-01, путь 1).
- Подтверждение (перекрёстно, F-01 путь 2 — сайт deveillance.com закрыт egress-прокси):
  `https://www.digitaltrends.com/cool-tech/this-smart-device-stops-sneaky-ai-devices-and-gadgets-from-listening-to-your-conversations/`,
  `https://sonicfield.org/kalypta-deveillance-inaudible-to-ai`,
  пост основательницы Aida Baradari на X (`https://x.com/aidaxbaradari/status/2100223250789970186`).
- Факты:
  - Компания: Deveillance, продукт: Kalypta.
  - Локальное приложение для macOS (работает на Apple Silicon), искажает исходящий аудиопоток
    звонка так, что собеседники слышат речь нормально, а системы распознавания речи получают
    искажённые данные.
  - Во внутренних тестах ИИ ошибается примерно в 2 словах из 3.
  - Доступность: закрытая бета, доступ по заявке на сайте разработчика, только macOS.
  - Цена не объявлена.
  - У той же компании есть более ранний продукт Spectre I — физическое устройство с возвратным
    депозитом $1199, глушит микрофоны в радиусе двух метров; Kalypta развивает ту же идею
    программно.
  - Дата анонса Kalypta: 16 сентября 2026.
- F-05: цены на сам Kalypta нет (не объявлена), поэтому в посте о ней не пишется; цена Spectre I
  названа с пометкой «возвратный депозит», без указания период/разовая — если упоминается, то
  только как контекст о компании, не как тариф Kalypta.

## Пост 3. «Второй мозг» для ИИ-агента: база знаний вместо повторного контекста

- Первоисточник: `https://vc.ru/ai/3140140-vtoroy-mozg-dlya-marketinga` — открыт целиком
  (F-01, путь 1).
- Факты:
  - Автор материала на vc.ru — Иван Юницкий.
  - Метод: структура из 6 файлов-ядра — о компании, о клиенте, об офере, о позиционировании,
    о голосе бренда, о доказательствах (только подтверждённые факты).
  - Назначение: ИИ-агент читает эту базу перед каждой задачей вместо того, чтобы пользователь
    заново пересказывал контекст о компании в каждом промпте.
  - Метод не привязан к одному сервису: годится для любого ИИ-агента с доступом к файлам проекта
    (в статье упомянуты Claude Code — файл CLAUDE.md, и Codex — файл AGENTS.md, как примеры того,
    куда кладётся такая база).
  - Точная дата публикации на странице не указана; в ленте vc.ru материал шёл без пометки
    «вчера» в отличие от соседних, отмеченных этим днём, — статья написана без привязки ко
    времени (метод, а не новость), в посте дата не упоминается вовсе (ШАГ 3, запасной приём для
    источников без чёткой даты).
- F-03: конкретных сторонних брендов, которым обязательна проверка, помимо примеров названий
  файлов Claude Code/Codex, нет — метод описан обобщённо, это допустимо.
