Если в последние дни лимиты <b>Claude</b> у кого-то из команды вдруг проседали сами по себе, без видимой причины, стоит проверить, не взломан ли аккаунт. 🔓

Anthropic разослала части пользователей Claude предупреждение: их данные для входа украли с помощью вредоносного ПО. Такие программы вытаскивают с заражённого компьютера сохранённые пароли и cookies. Украденные cookies сессии дают доступ к аккаунту без пароля и без повторного прохождения двухфакторной аутентификации.

Среди вредоносного ПО, которое использовали в этой атаке:

🦠 Vidar, LummaC2, StealC, RedLine, Acreed на Windows
🍎 Atomic Stealer на Mac

Anthropic принудительно завершила сессии пострадавших аккаунтов, удалила сохранённые способы оплаты и вернула деньги за списания, которые сделали злоумышленники. Выход из Claude сам по себе вредоносную программу с компьютера не убирает.

Отдельно сооснователь Refi Hub Нума Лунах попросил Claude найти приложение для расшифровки аудио и получил ссылку на сайт-клон, распространяющий вредоносное ПО. После переустановки Windows заражение вернулось само: в резервной копии лежал личный <b>навык (SKILL.md)</b> для Claude Code, который при каждой загрузке файла Claude незаметно переустанавливал вредонос.

Мне кажется, тут стоит запомнить одну вещь: файлы навыков для Claude Code по сути и есть исполняемый код, и относиться к ним стоит так же настороженно, как к любому скрипту, который вы не писали сами.

Если у кого-то в команде лимиты Claude в последнее время вели себя странно, выйдите из всех сессий, смените пароль и проверьте компьютер антивирусом. Ссылки на установку, которые предлагает Claude, стоит открывать через официальный сайт сервиса, а не переходить по ним напрямую.

Instagram теперь может урезать охват аккаунта, если за ним стоит ИИ-персонаж, который выдаёт себя за живого человека. 🤖

Meta ввела для таких страниц статус профиля <b>«AI-generated profile»</b>. Если владелец аккаунта не проставил статус, Instagram снижает охват публикаций. Причина простая: люди должны понимать, что общаются не с реальным человеком.

Если считаете, что ограничение применили по ошибке, можно подать апелляцию через панель Account Status.

Instagram и Meta в целом заблокированы в России как экстремистская организация, доступ обычно идёт через VPN. Но часть бизнеса всё ещё ведёт аккаунты в Instagram для зарубежной аудитории и клиентов за границей.

Мне кажется, требования к прозрачности ИИ в соцсетях будут только расти.

Если у вас в маркетинге есть страница с придуманным ИИ-персонажем, который ведёт диалог с подписчиками от имени бренда, сейчас подходящий момент проверить, стоит ли на ней статус «AI-generated profile». Иначе охват может начать падать без объяснимой причины, и разбираться придётся уже постфактум.
