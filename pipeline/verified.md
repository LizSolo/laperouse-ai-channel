## Пост 4. Антивирус и ИИ-агенты тормозят компьютер
- Первоисточник: https://habr.com/ru/articles/1099768/ (открыт целиком)
- Подтверждение: не требуется — первоисточник открыт целиком (F-01)
- Факты: загрузка CPU в фоне до исправления — около 67%; после исправления — около 12%; причина 1 — Windows Defender сканирует в реальном времени каждый файл, создаваемый/изменяемый ИИ-агентами (установки пакетов, копии рабочих файлов); причина 2 — кеши агентов (npm, Docker) по умолчанию лежат в AppData на системном диске C, даже если проекты открыты на другом диске; исправление — перенос кешей на другой диск (со ссылкой на старом месте) и добавление рабочей папки в исключения Windows Defender; диагностика — встроенные команды PowerShell (отчёт о нагрузке по процессам). Названные продукты: Windows Defender, Claude Code, Codex, npm, Docker.
- Числа поста: 67, 12.

## Пост 5. Кэширование промптов в Claude API
- Первоисточник: https://platform.claude.com/docs/en/build-with-claude/prompt-caching (открыт целиком)
- Подтверждение: https://vc.ru/ai/3213427-keshirovanie-promptov-v-claude-api (цифры совпадают)
- Факты: параметр cache_control включает кэширование повторяющегося блока запроса (инструкция, документ, список инструментов); кэш по умолчанию живёт 5 минут и продлевается без доплаты при каждом обращении; есть вариант на 1 час за отдельную цену; запись в кэш стоит дороже обычного ввода (×1,25 для 5-минутного, ×2 для часового); повторное чтение дешевле стандартно в 10 раз, у отдельных моделей — в 40 раз; минимальная длина кэшируемого блока — от 512 до 4096 токенов в зависимости от модели; проверка — поля usage «cache_creation_input_tokens» и «cache_read_input_tokens»; любое изменение системного промпта, инструментов или истории сообщений сбрасывает кэш.
- Числа поста: 5, 10, 40, 512.
