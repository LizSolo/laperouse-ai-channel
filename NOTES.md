# Агент(ы) для Telegram-канала LaperouseAI

## Задача (из обсуждения)

Настроить агента/агентов, которые:
- собирают новости из первоисточников (Anthropic и, возможно, другие AI-лабы)
- пишут краткий пересказ + личную оценку/комментарий к материалу
- постят это в Telegram-канал/группу

## Черновой набросок архитектуры

1. **Источники** — RSS/Atom-ленты блогов (у Anthropic, OpenAI и т.д. часто есть фиды), для остальных — периодический просмотр страницы через web-fetch.
2. **Планировщик** — задача по расписанию (cron-агент / routine), проверяет источники на новое, например раз в несколько часов.
3. **Дедупликация** — простое хранилище (файл или маленькая база) со списком уже опубликованного, чтобы не постить повторно.
4. **Обработка** — агент читает новый материал, пишет краткий пересказ и свою оценку в нужном тоне.
5. **Публикация** — пост в Telegram через Bot API (нужен токен бота и права на постинг в канал/группу).

## Ответы, полученные 2026-07-28

- **Бот и группа уже есть.** Тестовые посты сначала кидаем в группу, смотрим как выглядит, потом решаем по каналу. Название бота/токен — пришлёт отдельно.
- **Источники — шире, не только AI-лабы.** Нужны в целом последние новости про AI-технологии (не только Anthropic/OpenAI и т.п.), т.е. нужен более широкий список источников (тех-медиа, где выходят свежие AI-новости), не только один сайт (упоминался TechCrunch как пример, но одного источника мало).
- **Угол подачи / личная оценка:** каждую новость оценивать с точки зрения пользы для малого и среднего бизнеса, в любых нишах — кроме самих AI-компаний. Примеры того, что малый бизнес мог бы закрыть с помощью AI: свой сайт/приложение, бухгалтерия, юристы/договорной отдел (контракты), продажники, служба поддержки — в общем, обычные функции, которыми пользуется малый бизнес.
- **Тон текста:** не должно быть заметно, что текст написан ИИ — живой, человеческий стиль изложения.
- **Частота/расписание:** сводка каждый день в 9:00 по Таиланду.
- **Рабочий процесс:** сводка готовится → пользователь смотрит и решает, что постить и нужна ли правка, перед публикацией (человек в контуре, не полностью автономная публикация).
