## Пост 5. Anthropic расширяет Cyber Verification Program

- Первоисточник: https://www.anthropic.com/news/cyber-verification-program (открыт целиком, WebFetch)
- Факты:
  - Опубликовано 06.10.2026
  - Программа даёт специалистам по кибербезопасности доступ к Claude с ослабленными стандартными ограничениями — чтобы находить и исправлять уязвимости в системах
  - Три уровня доступа: Defense Access (анализ уязвимостей и реагирование на инциденты), Red Team Access (авторизованный пентест, только для организаций), Specialized Access (критически важные системы — авиация, энергосети)
  - С апреля по июль 2026 партнёры программы нашли 129 000 подтверждённых уязвимостей, больше 33 000 из них — критические или высокого уровня опасности
  - Подключение через портал portal.anthropic.com/programs/cvp
  - Программа касается безопасности кода и инфраструктуры пользователей, а не безопасности самой модели Claude (к T-04 не относится)
  - T-05: Claude — явное исключение из правила в RULES.md
