# Проверка фактов за 2026-09-06

## Пост 1. GPT-6 Astra на платных тарифах ChatGPT

Первоисточник: https://habr.com/ru/news/1078790/ (открыт целиком, WebFetch)
Подтверждение: https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html (найден и открыт
через поиск, независимая публикация)

Факты:
- GPT-6 Astra стала доступна пользователям платных тарифов ChatGPT: Plus, Pro, Business и
  Enterprise.
- Доступна также через API, Codex и интерфейс ChatGPT Work.
- Раскатка была поэтапной: сначала ограниченный набор организаций, к 5 сентября 2026 —
  все платные тарифы.
- На тарифах Pro, Business и Enterprise доступен более мощный режим GPT-6 Astra Pro.
- В Enterprise администратор включает модель на уровне рабочего пространства, по умолчанию
  она выключена.
- Протестировать модель без подписки на ChatGPT можно через сторонний сервис BotHub.
- Доступность из России отдельно не проверяется (T-05, исключение для ChatGPT).

## Пост 2. Telegram Serverless: боты без VPS

Первоисточник: https://habr.com/ru/news/1078906/ (открыт целиком, WebFetch)
Подтверждение: кросс-проверка через WebSearch — независимое описание на quasa.io
("Telegram Just Launched Real Serverless for Bots and It's Built for AI Agents") совпадает по
ключевым фактам: официальная бета-программа, доступ через BotFather, отсутствие необходимости
в VPS. core.telegram.org/bots/serverless — официальная документация Telegram, недоступна
через WebFetch (EGRESS_BLOCKED на уровне CONNECT), факт подтверждён кросс-проверкой (F-01,
запасной путь).

Факты:
- Telegram открыл бета-программу хостинга ботов на собственной инфраструктуре («Serverless»).
- Не требуется отдельный VPS, Docker-контейнер, настройка вебхуков и постоянный мониторинг
  сервера.
- Дата анонса: 2 сентября 2026.
- Доступ пока ограничен бета-программой; заявку можно подать через @BotFather, раздел
  «Serverless» → «Get access to Serverless».
- Подходит для прототипов, MVP и простых сценариев.
- Проекты с очередями, PostgreSQL, аналитикой и интеграциями со сторонними API всё ещё
  нуждаются в отдельной инфраструктуре — Serverless их не заменяет.

## Пост 3. Как формулировать запросы к нейросетям

Первоисточник: https://vc.ru/ai/3122570-kak-predprinimatelyu-rabotat-s-ii-bez-navykov-programmirovaniya
(открыт целиком, WebFetch)

Факты:
- Автор материала — сервис Strelka.Ai, российский агрегатор нейросетей с доступом без VPN.
- Дата публикации: 5 сентября 2026.
- Общая идея: общий запрос к нейросети даёт расплывчатый ответ, задачу нужно ставить как
  сотруднику.
- Четыре совета по формулировке запроса: указать результат (что, для кого, зачем нужно),
  добавить контекст (о продукте, аудитории, ограничениях), уточнить формат (объём, структуру,
  стиль), дорабатывать итерациями с точечной обратной связью, а не одним запросом.
- Примеры задач из статьи: письмо от SEO-специалиста, контент для карточки интернет-магазина,
  идеи для Reels косметического бренда.
