- Первоисточник: https://www.cnews.ru/news/line/2026-01-23_tochka_bank_zapustil_ii-assistenta
  (открыт напрямую).
- Подтверждение: то же сообщение продублировано на нескольких изданиях (comnews.ru, New
  Retail) с идентичными фактами по данным поиска; comnews.ru закрыт для WebFetch
  (`EGRESS_BLOCKED`), как новостной сайт в очередь на allowlist не ставится.
- Дата запуска: 23 января 2026.
- Для кого: продавцы Wildberries, более 500 000 адресатов, в фокусе — предприниматели с
  оборотом до 3 млн рублей в месяц.
- Что делает: формирует отчёт о прибылях и убытках, даёт рекомендации по росту продаж и
  маржи, строит графики динамики показателей и сравнение с конкурентами, выдаёт результат в
  PDF.
- Как подключить: пользователь передаёт API-токен Wildberries в Telegram-чат, заполняет
  шаблон себестоимости товаров, получает готовый анализ.
- Стоимость: источник называет бесплатным только первый квартал 2026 года; данных о цене
  после этого периода нет ни в первоисточнике, ни в найденных публикациях. В пост цена и
  слово «бесплатно» не идут (F-05/F-06): упоминается только сам механизм подключения через
  Telegram.
- Числа в посте: 500 000 (продавцов), 3 млн рублей (оборот) — оба подтверждены
  первоисточником.

## Тема 2. Контур.Фокус: ИИ-ассистент для проверки контрагентов

- Первоисточник (первый релиз): https://www.cnews.ru/news/line/2025-11-12_konturfokus_sozdal_ii-assistenta
  (открыт напрямую).
- Подтверждение (второй релиз, обновление): https://www.cnews.ru/news/line/2026-05-05_konturfokus_obnovil_ii-assistenta
  (открыт напрямую).
- Перекрёстно те же факты первого релиза видны в поисковой выдаче по companies.rbc.ru,
  russoft.org, spark.ru — сами страницы закрыты для WebFetch (`EGRESS_BLOCKED`), как
  новостные/агрегаторские сайты в очередь на allowlist не ставятся.
- Дата первого релиза: 12 ноября 2025. Дата обновления (второй релиз): 5 мая 2026.
- Первый релиз, что умеет: формирует ИИ-отчёт о компании с характеристикой по юридическим,
  санкционным и финансовым показателям; оценивает риски сотрудничества с учётом сценария
  сделки; в отдельных случаях рассчитывает оптимальный кредитный лимит для
  контрагента-покупателя. Работает в формате диалога с ИИ, а не через поиск и переход по
  вкладкам (цитата руководителя проекта Антона Ломовского).
- Обновление (5 мая 2026): отчёт стал доступен для скачивания и структурнее (направление
  деятельности, учредители, численность, судебные риски, взыскания, санкции); оценка рисков
  теперь учитывает роль контрагента, тип оплаты, предмет и сумму сделки; появилось сравнение
  рисков сразу по пяти контрагентам в одном сценарии сделки; можно загрузить договор
  текстом и получить анализ на основе матрицы рисков. Обработка данных — на локальных LLM
  «Контура», без передачи данных третьим лицам.
- Тарифы: по данным поиска (companies.rbc.ru, RUSSOFT, AKM.ru, не открыты напрямую) ассистент
  входит в тариф «Корпорация»; для остальных тарифов Контур.Фокуса (кроме «Бизнес», «Разовый»
  и «Экспресс») даётся тестовый период на три месяца, дальше — как платный модификатор. Ни
  один из двух напрямую открытых cnews.ru источников тариф не называет, поэтому в пост
  условия доступа идут с осторожной формулировкой «по части тарифов», без цифр (F-05/F-06).
- Числа в посте: пять (контрагентов в сравнении) — подтверждено обоими источниками cnews.ru.
