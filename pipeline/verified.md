## Пост 1. Параллельные AI-агенты: время против денег

Первоисточник: https://habr.com/ru/articles/1080948/
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: не требуется, первоисточник открыт целиком

Факты:
- Автор поставил эксперимент на трёх независимых задачах: текст посадочной страницы,
  письмо, программа часового эфира; на входе шесть файлов проекта общим объёмом 4141 слово
- Вариант 1, последовательный запуск одним агентом: 423 секунды (7 мин 3 сек), $2,74,
  оценка качества (слепое судейство) 44 балла
- Вариант 2, параллельный запуск через доску оркестрации, три независимых агента: время
  ожидания 307 секунд (5 мин 7 сек), машинное время 499 секунд, стоимость $6,15, оценка
  качества 52 балла
- Вариант 3, ручной параллельный запуск без оркестратора: время ожидания 361 секунда
  (6 мин 1 сек), стоимость $5,73, оценка качества близка к варианту 2
- Разница вариантов 1 и 2: по времени ожидания в 1,38 раза быстрее (423/307), по деньгам в
  2,24 раза дороже (6,15/2,74)
- Отдельно на оценку качества (12 прогонов судейства) потрачено $8,85 из $23,47 общих
  затрат на весь эксперимент
- Вывод автора: последовательный подход подходит, когда этапы связаны общим контекстом;
  параллельный через доску — для независимых задач, если экономия времени важнее переплаты;
  ручной параллельный запуск годится при малом числе разовых запусков без системы управления

## Пост 2. Как отличить AI-сайт от тысячи таких же

Первоисточник: https://vc.ru/ai/3132247-pochemu-sayty-na-osnove-ii-vyglyadyat-odnakovoi
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: не требуется, первоисточник открыт целиком

Факты:
- Автор — Иван Юницкий, публикация 10.09.2026
- Причина унификации: модели обучены на интернет-данных и выдают «статистическое среднее»
  на абстрактный запрос — синий градиент, скруглённые карточки, три колонки с иконками,
  шрифт Inter
- Первая причина проблемы: агент сам принимает дизайн-решения без явных ограничений
- Вторая причина: словесные описания вроде «сделай красиво» слишком абстрактны для модели
- Решение 1: показывать агенту 3-4 референса (скриншоты с Mobbin, Dribbble, CodePen) вместо
  словесного описания
- Решение 2: завести файл DESIGN.md в корне проекта с дизайн-токенами (цвета, шрифты,
  отступы, радиус скругления) и отдельным разделом запретов («запрещены градиенты»,
  «максимум два начертания шрифта на странице»); по словам автора, раздел с запретами важнее
  раздела с цветами
- Названные сервисы для извлечения дизайн-токенов: designmd.supply, Neuform, getdesign.md
- Названные скиллы-ревизоры готовых экранов: Impeccable, Better Interface — возвращают
  список замечаний по интерфейсу
- Инструмент Agentation — позволяет указать проблему прямо на экране, конвертирует замечание
  в бриф для агента с точным селектором элемента
- Порядок работы по автору: собрать референсы и общее описание → создать DESIGN.md с
  запретами → собрать один экран-эталон → прогнать через скилл-ревизор → точечно указать на
  оставшиеся проблемы

## Пост 3. GigaChat 3.5 Reasoning: открытые веса и сервер за миллионы

Первоисточник: https://habr.com/ru/companies/sberbank/articles/1080596/
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: https://vc.ru/ai/3131285-model-gigachat-35-reasoning-ot-sber

Факты:
- Модель — GigaChat 3.5 Reasoning, 432 млрд параметров всего, 28 млрд активных
  (mixture-of-experts), три MTP-головы для спекулятивного декодирования
- Веса опубликованы на Hugging Face в двух вариантах: ai-sage/GigaChat3.5-432B-A28B-Reasoning
  (FP8) и ai-sage/GigaChat3.5-432B-A28B-Reasoning-bf16 (BF16)
- Для локального запуска в примере использован сервер с 8 ускорителями NVIDIA H100
  (tensor parallelism, tp-size 8, ep-size 8)
- Без своего сервера модель можно попробовать бесплатно на giga.chat
- Обучение: после SFT модель целиком прошла online RL с шестью отдельными
  экспертами-специалистами (математика, код, агенты и другие), каждый со своей наградой,
  затем собранными обратно в одну модель через on-policy дистилляцию — заявленная экономия
  37% токенов на сложных математических задачах по сравнению со стандартным подходом
- Дата публикации — 10.09.2026 (vc.ru подтверждает тот же релиз в тот же день)

Факты:
- Уязвимость обнаружила Check Point Research (подразделение Check Point Software
  Technologies), обнаружение — июнь 2026, публикация отчёта — 08.09.2026
- Механизм: общий для разных аккаунтов ChatGPT внутренний сервис JFrog Artifactory работал
  как «общий буфер обмена» между контейнерами разных пользователей — один контейнер мог
  записать данные в свойства объекта, а другой аккаунт их прочитать
- Через эту уязвимость исследователи заставили ChatGPT обратиться к подключённому Gmail
  жертвы, прочитать данные из почты и передать их в чужую сессию, при этом в чате жертвы не
  было ничего подозрительного
- Под угрозой: содержимое писем, история переписки, вложения и любые другие сервисы,
  подключённые к аккаунту, в пределах выданных им прав
- К моменту публикации отчёта канал между аккаунтами уже был недоступен; OpenAI подтвердила,
  что использованный внутренний инстанс Artifactory выведен из эксплуатации
- Уязвимость на дату прогона неактивна — это разбор случившегося, а не открытая угроза

## Пост 8. Госуслуги захлёстывает поток заявлений от ИИ-агентов

Первоисточник: https://techcrunch.com/2026/09/10/ai-agents-are-flooding-public-services-with-new-requests/
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: не требуется, первоисточник открыт целиком

Факты:
- Исследователь Крис Шмитц называет явление «agentic flooding» — рост потока заявлений и
  жалоб, поданных с помощью ИИ-агентов
- Исследование охватило 84 случая потенциального «наводнения» в 11 юрисдикциях
- Британский жилищный омбудсмен: рост числа жалоб с 2 600 в 2022 году до 7 000 в 2025 году
- Американское Бюро защиты потребителей (CFPB): рост потока обращений в 5 раз
- Аналогичные скачки зафиксированы в бразильской судебной системе и германском парламенте
- Рост начался после выхода ChatGPT в 2022 году и продолжает ускоряться
- Ключевая оговорка исследователя: подавляющее большинство новых заявителей — люди, которые
  действительно имеют право на то, за чем обращаются, но раньше не подавали заявление из-за
  бюрократической сложности процесса
