# Проверка фактов за 2026-10-03

## Пост 1. Anthropic блокирует аккаунты Claude за VPN

- Первоисточник: https://www.cnews.ru/news/top/2026-10-02_rossiyanam_prigotovitsya (открыт целиком, WebFetch)
- Подтверждение: https://news.bloomberglaw.com/crypto/crypto-firm-okx-bars-claude-use-in-hong-kong-after-suspension и https://www.investing.com/news/stock-market-news/anthropic-targets-loopholes-used-by-chinese-firms-to-access-claude-ft-reports-4774998 (независимые публикации, тот же механизм: детектирование VPN и гео-сигналов, точечные блокировки аккаунтов)
- Факты:
  - Дата публикации: 02.10.2026, 10:36
  - Anthropic начала волну блокировок аккаунтов Claude, которая стартовала в Гонконге
  - Причина — «подозрительные сигналы» при подключении через VPN из стран, где Claude официально не работает
  - Признаки, которые Anthropic использует для детекции: IP-адрес из неподдерживаемой страны, иностранные платёжные данные, несовпадение часового пояса устройства с заявленным регионом
  - Claude проверяет геолокацию по IP в реальном времени на каждой сессии, а не только при входе (подтверждено независимой публикацией)
  - Затронутые регионы: Гонконг, Макао, материковый Китай; Россия в зоне риска, так как Claude там официально не работает
  - Публичного заявления о новой политике Anthropic не делала; пользователи получают письма о «нарушении правил использования»
  - Пример из подтверждающего источника: криптобиржа OKX запретила сотрудникам использовать Claude через VPN при поездках в Китай/Гонконг после того, как корпоративный аккаунт биржи ненадолго заблокировали
  - Контекст блокировок — претензии Anthropic к китайским компаниям (Moonshot AI, DeepSeek) в дистилляции моделей

## Пост 2. «Гига Писарь»: голосовой набор текста на устройстве

- Первоисточник: https://habr.com/ru/companies/gigapisar/articles/1089818/ (открыт целиком, WebFetch)
- Факты:
  - Дата публикации: 02.10.2026
  - Приложение для голосового ввода текста на Android, open source, бесплатное
  - Распознавание речи идёт моделью GigaAM (Сбер) прямо на устройстве, без интернета и без отправки голоса на сервер
  - Распространяется APK-файлом с сайта проекта и GitHub, не через Google Play; требуется скачать модель весом около 225 МБ
  - Диктовка работает через плавающую кнопку или кнопку громкости в любом приложении с текстовым полем — мессенджеры, заметки, почта, браузер
  - Есть функция «Править на лету» — автоматическая корректировка текста голосом
  - Поддерживается интеграция с чат-ботами (DeepSeek, OpenAI) для последующей обработки продиктованного текста

## Пост 3. Shopify Canvas: интернет-магазин через диалог с ИИ

- Первоисточник: https://techcrunch.com/2026/10/01/shopify-debuts-canvas-a-way-to-build-online-stores-by-chatting-with-ai/ (открыт целиком, WebFetch)
- Подтверждение: https://www.cbc.ca/lite/story/1.6377570 и официальный комментарий Shopify, процитированный там же (ограничение по России/Белоруссии подтверждено независимо через community.shopify.com)
- Факты:
  - Дата запуска: 01.10.2026
  - Canvas — инструмент Shopify для создания и редактирования интернет-магазина через чат с ИИ-ассистентом Sidekick
  - Пользователь описывает желаемые изменения текстом, Canvas показывает результат в реальном времени на реальном коде магазина, а не на макете/превью
  - Доступен только на компьютере, мобильной версии нет
  - Ранняя стадия: нет поддержки сторонних тем, приложений-расширений, мультивалютности и переводов
  - Цена в источнике не указана
  - Shopify официально не принимает новых продавцов из России и Белоруссии и отключил приём платежей (checkout) для уже действующих продавцов из этих стран; сроков возобновления компания не называет (заявление пресс-службы Shopify, независимо подтверждено CBC)
