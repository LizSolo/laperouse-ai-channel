# Проверка фактов за 2026-10-04

## Пост 1. RAG: что это и когда нужен бизнесу

- Первоисточник: https://vc.ru/ai/3173511-chto-takoe-rag-i-kak-neirosset-otvechaet-po-dokumentam-kompanii (открыт целиком, WebFetch)
- Факты:
  - Дата публикации: начало октября 2026 (точная дата не отображается на странице, в листинге раздела — «вчера» на момент сбора 04.10)
  - RAG (Retrieval-Augmented Generation) — поиск релевантных фрагментов документов перед тем, как модель генерирует ответ
  - Два этапа: документы нарезаются на куски и превращаются в эмбеддинги в векторной базе; вопрос тоже превращается в эмбеддинг, система находит похожие куски и передаёт их модели с инструкцией отвечать только по найденному
  - Примеры результатов компаний: Альфа-Банк — ответ за 3 секунды вместо минуты; Московская биржа — 15 секунд вместо 18 минут при поиске по 1500 регламентам; Morgan Stanley — больше 98% команд используют RAG-ассистента; LinkedIn — сокращение времени решения задач на 28,6%
  - Исследование Стэнфорда: даже юридические ИИ-сервисы с RAG ошибались в 17-33% случаев
  - Типичные ошибки RAG: поиск приносит не те куски; модель отвечает, даже когда информации в базе нет; нарезка разделяет правило и исключение по разным кускам; в базе одновременно лежат старая и новая версия документа
  - RAG не нужен, если база меньше 500 страниц (примерно 200 000 токенов), если нужно поменять стиль ответов (а не добавить знания), или если нужны актуальные данные из интернета в реальном времени
  - Готовые решения: ChatGPT Business, Claude Team (от $20), Яндекс Нейроэксперт, Yandex AI Studio, Cloud.ru Managed RAG, открытое решение Open WebUI
  - Пример расчёта на 1000 страниц базы и 1000 вопросов в день: эмбеддинги — несколько рублей, хранение — 10-100 ₽, ответы — 75-78 000 ₽ в месяц; разработка под ключ — от 200 тыс. до 5 млн рублей
  - Правовые ограничения в России: ФИО, телефоны и паспортные данные нужно хранить на территории РФ; передача персональных данных за границу требует уведомления Роскомнадзора; штрафы — от 1 млн до 18 млн рублей
  - Автор статьи (Павел Молянов) сам сделал на базе RAG бота «Архивариус» для чата Нейроцеха, который отвечает по 200+ гайдам и 80 лекциям

## Пост 2. Вайбкодинг без навыков программирования

- Первоисточник: https://vc.ru/ai/3168737-kak-nachat-vajbkodit-bez-znanij-programmirovaniya (открыт целиком, WebFetch)
- Факты:
  - Дата публикации: 01.10.2026
  - Автор (Павел Молянов) не программист, создал вайбкодингом Telegram-бота на 46 000 пользователей, несколько сайтов, расширение для Chrome и RAG-систему
  - Главная рекомендация: использовать ИИ-агента, который работает прямо с файлами на компьютере (создаёт папки, пишет код, устанавливает программы, запускает проекты и сам правит ошибки), а не обычный чат-бот
  - Практики: начинать с небольших проектов, которые можно проверить самостоятельно; проводить структурированное интервью с агентом перед началом работы; фиксировать договорённости в файле spec.md; вести историю через Git/GitHub; держать файл контекста проекта (CLAUDE.md); делать одну задачу за раз; открывать новый чат под каждую новую задачу; просить разных агентов отдельно проверять логику, безопасность и тесты
  - Инструменты и цены: Codex от OpenAI — $20/мес, встроен в ChatGPT; Claude Code от Anthropic — $20/мес; Cursor — редактор с встроенным агентом; Lovable, Bolt, Replit — браузерные конструкторы
  - Критическое правило: никогда не вставлять пароли и API-ключи в чат с агентом, хранить их в файле .env; перед тем как показывать результат клиентам или подключать платежи и данные пользователей — проверять безопасность отдельно
  - Справочно (ранее проверено и опубликовано 13.09.2026, https://www.cnews.ru/news/top/2026-09-11_odin_iz_krupnejshih_ii-instrumentov): Cursor заблокирован для пользователей из России после покупки Anysphere SpaceX за $60 млрд — упоминается в посте как оговорка к совету

## Пост 3. Моды Claude Code

- Первоисточник: https://claude.com/blog/claude-code-mods (открыт целиком, WebFetch)
- Подтверждение: https://vc.ru/ai/3171794-kastomizatsiya-claude-code-novye-mody-ot-anthropic (независимая публикация, те же факты: TypeScript-модификации, перехват событий, установка через /plugin, предупреждение о полном доступе к компьютеру)
- Факты:
  - Дата публикации: 01.10.2026
  - Mods — небольшие функции на TypeScript, которые меняют поведение Claude Code: переписывают промпт перед отправкой модели, блокируют или переписывают вызов инструмента, одобряют или отклоняют запрос разрешения, скрывают секреты из вывода инструмента
  - Система основана на событиях: Claude Code генерирует событие на каждую операцию, мод его перехватывает; при нескольких модах они видят событие в порядке загрузки
  - Встроенный пример — мод `/diff`
  - На корпоративных планах (Enterprise) по умолчанию включён мод `sec-default`, который блокирует опасные операции
  - Устанавливаются через команду `/plugin` в CLI или из каталога Claude (claude.ai/directory)
  - Прямая цитата предупреждения: «Mods run with the same access to your machine as Claude Code itself. They aren't sandboxed, and you should only install mods from sources you trust»

## Пост 4. Bitrix24: MCP или API для интеграции ИИ-агентов

- Первоисточник: https://www.bitrix24.ru/journal/mcp-vs-api/ (открыт целиком, WebFetch)
- Факты:
  - Дата публикации: 02.10.2026
  - API — инструмент для разработчиков с заранее зафиксированным сценарием на конкретную задачу; MCP (Model Context Protocol) — протокол для ИИ-агентов, которые сами выбирают нужное действие из доступного набора под каждый новый запрос
  - Пример: менеджер просит агента «найди сделки без задач на неделю и создай по ним задачи» — агент сам определяет последовательность действий
  - Практические советы: начинать с пилота на одной рутинной задаче, не подключать все функции сразу; ограничивать права агента только нужными инструментами; вести журнал действий агента; подключать только проверенные/одобренные MCP-серверы
  - Риски безопасности: вредоносные инструкции, спрятанные в данных, которые читает агент; изменение поведения ранее проверенного сервера; избыточные права агента относительно прав самого сотрудника
