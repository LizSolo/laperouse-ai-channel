## Пост 1. Appius-PLM: локальный ИИ-поиск по данным предприятия

- Первоисточник: https://www.cnews.ru/news/line/2026-10-07_iskusstvennyj_intellekt (открыт целиком, WebFetch)
- Факты:
  - Опубликовано 07.10.2026
  - Appius-PLM — российская PLM-система (управление жизненным циклом изделия), разработчик — компания Appius
  - В новой версии ИИ работает как прикладной инструмент поиска по корпоративным данным, запрос формулируется обычным языком
  - Умный текстовый поиск: индексируются PDF, TXT, вкладка «Свойства», описания технологических переходов; учитываются словоформы, синонимы, неполные номера, замена русских букв латиницей
  - Смысловой поиск: документы находятся по смыслу запроса, а не по совпадению слов (пример в источнике — запрос про соединение валов под углом находит материалы про карданные шарнирные муфты); ИИ формирует краткий и подробный ответ со ссылками на источники и отмечает сомнения в точности документов
  - Интуитивный поиск элементов: отбор по сложным критериям на простом языке без специальных запросов
  - Есть точные настройки: исключение по слову, отключение поиска по синонимам и смыслу, поиск точной подстроки
  - Весь ИИ-контур разворачивается локально, по словам разработчиков — без доступа в интернет; модель и векторная база работают в инфраструктуре пользователя
  - В системе хранится конструкторская и технологическая документация, нормативные документы, коммерческая информация, в том числе третьих лиц
  - В планах — обучаемые ИИ-агенты для рутинных и многошаговых операций (следующий этап, пока не реализовано)
  - Количественных результатов внедрения (экономия времени, эффект) в статье нет
  - T-05: сервис российский, локальное развёртывание — отдельной пометки не требует

## Пост 2. Claude Max против ChatGPT Pro: как читать «в 5 раз выгоднее»

- Первоисточник: https://habr.com/ru/articles/1091556/ (открыт целиком, WebFetch)
- Факты:
  - Автор — Александр Майорский (WebProd), разбор основан на данных аналитической компании SemiAnalysis
  - Тарифы и их API-эквивалент по оценке SemiAnalysis:
    - Claude Pro — $20/мес, эквивалент $1 178
    - ChatGPT Plus — $20/мес, эквивалент $211
    - Claude Max 5x — $100/мес, эквивалент $5 725
    - ChatGPT Pro ($100) — эквивалент $1 055
    - Claude Max 20x — $200/мес, эквивалент $11 726
    - ChatGPT Pro ($200) — эквивалент $2 084
  - Разрыв в API-эквиваленте — около 5,4-5,6 раза
  - По оценке SemiAnalysis, Max 20x с Opus 5.5 даёт около 28,6 млрд токенов в месяц, ChatGPT Pro за $200 с GPT-6.1 Sol — около 10,2 млрд токенов (разрыв по токенам около 2,8 раза)
  - В Artificial Analysis Intelligence Index: Opus 5.5 — 58 баллов, GPT-6.1 Sol — 52 балла
  - На одну задачу Opus 5.5 тратит примерно втрое больше токенов на рассуждение, стоимость задачи выше примерно в 8,3 раза ($5,98 против $0,72)
  - На флагманском уровне у GPT-6 Astra (ChatGPT Pro $200) и Claude Fable 5.1 (Max 20x) одинаковый Intelligence Index — 53 балла
  - Вывод автора: разрыв «в 5,6 раза» в деньгах — это стоимость доступного объёма работы, а не объём реально выполненных задач; сравнивать подписки правильнее по числу закрытых задач в своих процессах
  - Цены приведены в долларах США за месяц, годовые тарифы в статье не упоминаются
  - T-05: Claude — исключение из правила в RULES.md, пометка про доступность из России не нужна; ChatGPT — тоже исключение

## Пост 3. Claude теперь работает внутри Google Документов, Таблиц и Презентаций

- Первоисточник: https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides (открыт целиком, WebFetch)
- Факты:
  - Опубликовано 06.10.2026, статус — публичная бета
  - Расширение Claude for Google Workspace открывает чат с Claude в боковой панели рядом с открытым документом, таблицей или презентацией
  - В Docs: правит формулировки, меняет стиль заголовков, для крупных правок показывает карточки изменений на подтверждение
  - В Sheets: пишет формулы, создаёт сводные таблицы и диаграммы, добавляет вкладки; для объединения и очистки данных может обработать диапазон в Python и вернуть результат в таблицу
  - В Slides: создаёт слайды по существующим макетам и темам, проверяет наложение элементов, выход за границы слайда и читаемость текста
  - Два режима: «Ask before edits» (по умолчанию, каждое изменение подтверждается) и «Accept all edits» (без остановок)
  - Модели, коннекторы и скиллы обычного Claude доступны в этой же панели
  - Отдельно вышли коннекторы Google Docs/Sheets/Slides (тоже бета) — через них Claude создаёт и редактирует файлы прямо из чата; доступ Claude соответствует правам пользователя в Google
  - Доступно на всех платных тарифах Claude; на Team и Enterprise владелец или primary owner сначала включает коннекторы; на Enterprise дополнительно доступны Compliance API, CMEK и экспорт аудита через OpenTelemetry
  - Установка: расширение берётся в Google Workspace Marketplace, затем в файле — Extensions → Claude → Open Claude; администраторы могут развернуть расширение на домен или группы через Google Admin console
  - Ограничение: открытие панели рядом с документом работает «on supported setups», то есть не на всех конфигурациях; бесплатный тариф Claude в статье не упоминается
  - T-05: Claude — исключение из правила в RULES.md, пометка про доступность из России не нужна

## Пост 4. SynthID: сайт, который проверяет, сгенерирован ли файл ИИ

- Первоисточник: https://techcrunch.com/2026/10/07/googles-new-synthid-website-can-identify-ai-generated-media/ (открыт целиком, WebFetch)
- Факты:
  - Опубликовано 07.10.2026, сайт synthid.com открыт для всех с вторника (06.10.2026); до этого доступ был только у журналистов и исследователей с Google I/O 2025
  - Проверяет изображения, видео и аудио на наличие невидимой метки SynthID, которую Google встраивает в контент своих моделей (Nano Banana, Veo, Lyria, Gemini, Flow и другие) с 2023 года
  - Как пользоваться: загрузить файл на сайт; проверка также встроена в приложение Gemini и браузер Chrome
  - Поддерживаемые форматы: изображения — JPG, JPEG, PNG, BMP, WEBP, AVIF, HEIC, HEIF, TIFF, TIF, GIF; видео — MP4, MOV, WEBM; аудио — WAV, MP3, OGG, FLAC, AAC, M4A
  - Ограничение: распознаёт только контент с собственной меткой SynthID, то есть созданный моделями, которые её используют; контент из других источников может не определить
  - Поддержку заявили OpenAI, Nvidia, Kakao, Apple собирается добавить её позже; у OpenAI есть собственный отдельный сервис проверки
  - По данным Google, сервис обрабатывает около 1 млн запросов на проверку в день
  - Цена в статье не указана
  - T-05: сервис доступен всем через веб, без ограничения по стране в статье не упомянуто — отдельной пометки не требуется

## Пост 6. Claude Haiku 5.5: дешевле и быстрее для массовых задач

  - Ограничения по кибербезопасности строже, чем у Haiku 4.5
  - Применения: массовые задачи с ограниченным бюджетом (суммаризация, компакция контекста, запросы к базам данных, классификация), субагент при работе с кодом вместе с Opus 5.5 или Sonnet 5.5, живая поддержка клиентов, автоматизация в браузере
