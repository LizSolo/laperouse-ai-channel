# Проверка фактов за 2026-08-23

## 1. МТС Web Services (MWS Cloud) — стоимость внедрения ИИ в России

Первоисточник: https://www.cnews.ru/news/top/2026-08-19_eksperty_zafiksirovali_pochti (открыт
целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- Исследование MWS Cloud (входит в МТС Web Services): средняя стоимость внедрения ведущих
  больших языковых моделей в России выросла с 13,7 млн руб. в 2025 году до 38,8 млн руб. летом
  2026 года — рост почти втрое (в 2,8 раза).
- Причина: новые модели требуют больше видеопамяти и более мощных GPU, а цены на GPU в мире
  продолжают расти на фоне конкуренции в ИИ-индустрии.
- 47% опрошенных ожидают дальнейшего роста цен на GPU-ресурсы к осени 2027 года.
- Директор MWS Cloud Павел Воронин: когда покупка своего железа перестаёт быть экономически
  оправданной, российский бизнес переходит на более компактные модели, оптимизирует вычисления
  или переезжает в облако, где расходы привязаны к фактическому использованию, а не к
  капитальным вложениям заранее.
- Потребление китайских LLM (Qwen, GLM, Kimi) через платформы MWS выросло более чем в 11 раз в
  первом полугодии 2026 по сравнению со всем 2025 годом (тот же факт уже публиковался 18.08 в
  привязке к другому источнику — в посте не используется повторно).
- Дата публикации: 19.08.2026.

## 3. Свой MCP-сервер за двадцать минут

Первоисточник: https://vc.ru/ai/3090104-kak-podklyuchit-claude-i-cursor-k-mcp-serveru (открыт
целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- MCP (Model Context Protocol) — открытый протокол для подключения ИИ-моделей к внешним
  источникам данных без написания отдельного REST-бэкенда под каждую интеграцию.
- Инструкция: установить пакетный менеджер uv, создать сервер на фреймворке FastMCP (Python),
  подключить его к базе данных (в примере — PostgreSQL в режиме только для чтения), затем
  зарегистрировать сервер в конфигурационном файле клиента (`.cursor/mcp.json` для Cursor,
  аналогично для Claude Desktop) и перезапустить приложение.
- Поддерживаемые клиентские приложения из статьи: Cursor, Claude Desktop, Windsurf, Zed.
- Дата публикации: 22.08.2026.

## 4. Google Workspace, Allowlisted Domains API

Первоисточник: https://workspaceupdates.googleblog.com/2026/08/allowlisted-domains-api-now-generally-available.html
(открыт целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- Новый API даёт возможности Create, Delete, List и Get для списка доверенных (allowlisted)
  доменов — программное управление вместо ручного редактирования в консоли администратора.
- Фильтрация записей по точному совпадению домена.
- Доступно всем клиентам Google Workspace; нужны права администратора на управление доменами
  либо соответствующее разрешение на управление allowlist.
- Функциональность для reseller-управляемых сценариев не поддерживается.
- Запуск объявлен 20.08.2026, постепенный rollout начался 19.08.2026 и займёт до 15 дней до
  полного охвата.

## 5. Anthropic, Claude Managed Agents — skills из GitHub-репозитория

Первоисточник: https://platform.claude.com/docs/en/release-notes/overview, запись за 07.08.2026,
со ссылкой на https://platform.claude.com/docs/en/managed-agents/skills#load-skills-from-a-github-repository
(оба открыты целиком, WebFetch). Второй источник не требуется по F-01.

Факты:
- Сессия Claude Managed Agents теперь может подгружать skills (переиспользуемые инструкции и
  workflow для агента) прямо из смонтированного на сессию GitHub-репозитория.
- Все skills из папки `.claude/skills` в корне репозитория обнаруживаются автоматически при
  старте сессии и становятся доступны агенту в этой сессии — без ручной загрузки файлов.
- Skills из репозитория используют тот же формат `SKILL.md`, что и вручную загруженные
  пользовательские skills.
- Обнаружение происходит один раз за сессию, по состоянию репозитория на момент старта сессии
  (последующие изменения в репозитории до конца сессии не подхватываются).
- Дата публикации записи в release notes: 07.08.2026.
