# Проверка фактов за 2026-09-12

## Пост 1. DLP для LLM: обезличивание запросов сотрудников

Первоисточник: https://habr.com/ru/companies/agima/articles/1081356/
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: не требуется, первоисточник открыт целиком

Факты:
- Компания: AGIMA, автор — Андрей Непряхин (CTO), публикация 11.09.2026
- Проблема: при прямой замене имени на токен один и тот же человек в разных сообщениях
  получает разные токены, и это ломает поиск по сотруднику во внутренней базе
- Решение: запросы идут через внутренний прокси-шлюз, который на лету находит персональные
  данные, связывает их с одним внутренним entity_id через сопоставление сущностей и только
  потом отправляет обезличенный текст во внешнюю модель
- Маппинг «токен → сотрудник» живёт на стороне шлюза 2 часа и не длиннее 500 токенов на сессию,
  наружу (во внешнюю модель) никогда не уходит
- Одно и то же имя в разных падежах и в транслитерации сводится к одному entity_id
- Четыре режима работы правил: mask (значение прячется, модель получает типизированный токен
  вида [PERSON_1]), block (запрос останавливается), warn (нужно подтверждение), allow (значение
  передаётся как есть, если это разрешено политикой)
- Тестовый набор для проверки: шесть грамматических падежей, варианты транслитерации,
  повторные упоминания одного человека, попытки подмены токена, потоковые ответы

## Пост 2. МФО выдали заём мошеннику по фото паспорта

Первоисточник: https://habr.com/ru/companies/smartengines/articles/1081388/
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: не требуется, первоисточник открыт целиком

Факты:
- Компания: Smart Engines (продвигает свою антифрод-платформу), публикация 11.09.2026
- Случай: на россиянку оформили около 60 микрозаймов на сумму больше 2,5 млн рублей, для
  оформления мошенникам хватило одной фотографии её паспорта
- Больше года женщина сталкивается с угрозами коллекторов, больше 20 МФО до сих пор пытаются
  взыскать долг
- Причина: МФО проверяли только сам факт наличия фото паспорта, не проверяя подлинность
  документа и не сверяя лицо человека с фото в документе
- Что рекомендует делать иначе: проверка подлинности документа, проверка живости (liveness),
  сверка лица с фото в документе, считывание машиночитаемой зоны и NFC-чипа документа,
  обработка данных локально без передачи третьим лицам
- Штрафы: МФО грозит до 400 тыс. рублей, за утечку персональных данных — от 15 до 20 млн рублей
- Контекст рынка: за период с 2025 по середину 2026 года в России произошли утечки из 326 баз
  данных, в них попало 1,175 млрд записей

## Пост 3. Google Workspace: перенос команды с Microsoft при настройке

Первоисточник: http://workspaceupdates.googleblog.com/2026/09/seamlessly-import-your-team-and-data-from-Microsoft-to-Google-Workspace-during-setup.html
(открыт целиком через WebFetch, F-01 — путь «первоисточник открыт»)
Подтверждение: не требуется, первоисточник открыт целиком

Факты:
- Публикация 11.09.2026, статус — общедоступный релиз (GA), до этого была бета для малого
  бизнеса
- Что переносится одним прогоном: учётные записи пользователей, почта, файлы OneDrive,
  события календаря, контакты, задачи
- Автоматически переносится до 10 пользователей Microsoft; для большего числа есть отдельная
  инструкция в Справочном центре
- Условия по тарифам: на гибком тарифе (Flexible Plan) можно импортировать сразу после
  подтверждения домена; на годовом/фиксированном тарифе нужно сначала докупить лицензии
- Что нужно для переноса: данные глобального администратора Microsoft-аккаунта, завершённая
  верификация домена и активация MX-записей; можно исключить часть пользователей или категорий
  данных из переноса
- Доступно сразу для доменов Rapid Release и Scheduled Release
- Аудитория функции: администраторы рабочего пространства, с акцентом на малый бизнес и
  учебные заведения

## Пост 4. ChatGPT Business: платные места Premium

Первоисточник: https://openai.com/index/premium-seats-chatgpt-business/
(openai.com закрыт для автоматических запросов — 403, проверено 12.09; факт совпадает
дословно не меньше чем в двух независимых публикациях, F-01 — второй путь)
Подтверждение: https://community.openai.com/t/introducing-chatgpt-business-premium-seats/1392591
и https://www.cio.com/article/4207908/openai-targets-heavy-users-with-premium-chatgpt-business-seats.html

Факты:
- Анонс 25.08.2026, давность на дату прогона 12.09 — 18 дней (T-11 пройден, T-07 требует
  назвать давность в тексте)
- Место Premium стоит $100 в месяц при годовой оплате или $125 в месяц при помесячной оплате
- Place Premium даёт впятеро больше объёма использования, чем место Standard, и снимает
  пятичасовое окно ограничения
- Место Standard стоит $25 в месяц при помесячной оплате или $20 в месяц при годовой
- Места Standard и Premium можно смешивать в одной команде, назначать и переназначать по
  сотруднику без перевода всей команды целиком
- Ограниченное предложение для тех, кто подключит Premium рано: рабочие кредиты $100 (2500
  штук) за каждое место Premium, максимум $500 за пять мест
