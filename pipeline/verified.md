## Пост 1. Microsoft Copilot: единое приложение для личных и рабочих задач

- URL первоисточника: https://vc.ru/ai/3159222-microsoft-obnovlennyj-copilot-instrumenty-dlya-biznesa (открыт целиком, пересказ Bloomberg от 25.09)
- URL подтверждения: https://www.geekwire.com/2026/microsoft-unveils-all-in-one-copilot-app-taking-on-anthropic-and-openai-in-new-push-to-boost-adoption/ (найден поиском, факты о слиянии приложений и разделах Home/Code/Autopilot совпадают)
- Путь по F-01: первоисточник (vc.ru) открыт целиком; факт о слиянии дополнительно совпадает в независимой публикации GeekWire, найденной поиском.
- Факты: Microsoft объявила 25 сентября 2026 года о слиянии личного приложения Copilot и корпоративного Microsoft 365 Copilot в одно приложение. Компания отказывается от отдельного развития потребительского ассистента в пользу фокуса на корпоративных клиентах. Новые разделы: Home (чат вместе с агентом Cowork), Code (создание приложений и автоматизаций текстовым запросом на базе GitHub Copilot), Autopilot (собственные ИИ-агенты пользователя с настраиваемыми правами доступа). Личные и рабочие/учебные аккаунты разделены внутри одного приложения: данные между ними не передаются. Microsoft 365 официально не работает для бизнеса в РФ (подтверждено поиском по нескольким российским обзорам GigaChat/Copilot), точных цен и даты полного развёртывания во всех регионах в материале нет.
- Российский контекст (справочно, без привязки к конкретным тарифам, поиском по нескольким обзорам 2026 года): в России как замена доступны отечественные корпоративные ИИ-ассистенты, например GigaChat Business/Enterprise от Сбера (в том числе в составе SberOffice) — с пакетной или потоковой оплатой по факту использования и версией для развёртывания на своей инфраструктуре.

## Пост 2. DBA Agent Сбера: автоматизация техподдержки баз данных

- URL первоисточника: https://habr.com/ru/companies/sberbank/articles/1086740/ (открыт целиком, официальный блог Сбербанка на Хабре)
- Путь по F-01: первоисточник открыт целиком.
- Факты: агент работает на базе PostgreSQL-совместимой СУБД Platform V Pangolin DB, обслуживает парк более 800 экземпляров. Три обработчика: StatisticsHandler (VACUUM/ANALYZE), DiskSpaceHandler (очистка дискового пространства, анализ через SSH), PlannedMaintenanceHandler (плановые остановки и запуски по расписанию). LLM (GigaChat) используется примерно в 10% случаев — для извлечения данных из свободного текста тикетов. За период 4 мая — 2 июня 2026: обработано 10 182 тикета за 30 дней, 99,6% автоматизации по StatisticsHandler, рост объёма обработанных задач на 2426% к предыдущему периоду, потреблено ~2,6 млн токенов за месяц, в среднем 260 токенов на тикет. Это внутренняя разработка Сбера, не продукт для внешних клиентов; авторы отмечают, что 80% кода написано и отредактировано с помощью LLM, что позволяет другим компаниям повторить подход самостоятельно.

## Пост 3. Маршрутизация между ИИ-моделями для экономии

- URL первоисточника: https://habr.com/ru/companies/hexlet/articles/1086774/ (открыт целиком, блог компании Hexlet на Хабре)
- Путь по F-01: первоисточник открыт целиком.
- Факты: маршрутизация — автоматический выбор модели под конкретную задачу по её сложности. Пример из статьи: простой запрос («где мой заказ») направляется к Mistral Small, сложный запрос с несколькими проблемами — к Claude Sonnet. В сценарии с автономным агентом исследование архитектуры доверяют сильной модели, а написание кода по готовому контракту — более экономичной версии; выбор модели зависит от уровня неопределённости на каждом шаге задачи. Инструменты для маршрутизации, названные в статье: LiteLLM, OpenRouter. Ссылка на исследование Arize и Fireworks: более дорогая модель может завершить сложную задачу дешевле, потому что ей требуется меньше повторных исправлений — экономию нужно считать по стоимости готового проверенного результата, включая переделки, а не по цене токена.

## Пост 4. ИИ-ассистент для ЖКХ: три ограничения перед запуском

- URL первоисточника: https://yandex.cloud/ru/blog/ai-product-without-developers-proptech-case (открыт целиком, блог Yandex Cloud)
- Путь по F-01: первоисточник открыт целиком.
- Факты: автор — Михаил Михайлов, руководитель продукта платформы «Домиленд» (PropTech-сервис в экосистеме Яндекса). Ассистент для ЖКХ работает через чат: распознаёт показания счётчиков по фото, информирует о расходе ресурсов, создаёт заявки в управляющие компании. Разработка заняла календарно два месяца одним человеком не на полную ставку. Использованы Yandex AI Studio, MCP-сервер, собственный function loop для контроля вызовов функций, адаптеры для API разных управляющих компаний. Три ключевых ограничения, которые команда сформулировала по опыту: (1) модели нельзя доверять критичные операции записи без контроля, (2) обязательна строгая авторизация, чтобы данные одного жителя не утекли другому, (3) при работе с историей диалога модель рискует сгенерировать неточный ответ. Дата публикации — 17 сентября 2026 года.

## Пост 5. Gemini 3.8 Flash: вводная цена до конца года

- URL первоисточника: https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/ (открыт целиком, официальный блог Google)
- Путь по F-01: первоисточник открыт целиком.
- Факты: Google представила Gemini 3.8 Flash и специализированную Gemini 3.8 Flash Cyber 2 сентября 2026 года. Обычная 3.8 Flash даёт заметный прирост по сравнению с 3.7 Flash и по качеству на сложных инженерных и многошаговых задачах местами приближается к более дорогим топовым моделям. Доступна через Google AI Studio, Android Studio, Gemini Enterprise, подписки Google AI Pro/Ultra. Вводная цена, действующая до 31 декабря 2026 года: $0,75 за 1 млн входных токенов и $3,75 за 1 млн выходных токенов. Flash Cyber — версия для задач кибербезопасности (например, команда Chrome получила с ней в 2,6 раза больше корректных патчей, чем с конкурентами); доступ к ней идёт через отдельную программу Fairwind, в пост не включается, чтобы не смешивать две разные темы (X-09). Доступ к Gemini API из России ограничен обычными способами оплаты (общий факт по продуктам Google, не детализирован в этой статье).
