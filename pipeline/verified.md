# Проверка фактов за 2026-09-01

## Пост 1. Кража сессий Claude инфостилерами + фейковая ссылка Claude Code

Первоисточник 1: https://vc.ru/ai/3109912-anthropic-predupredila-o-kraze-dannyh-polzovatelej-claude
(открыт целиком, WebFetch)
Первоисточник 2: https://vc.ru/ai/3110466-kak-predprinimatel-stal-zhertvoy-krazhi-dannyh-cherez-claude-code
(открыт целиком, WebFetch)
Подтверждение: независимые публикации на английском (Help Net Security, esecurityplanet.com,
securityaffairs.com, cybersecuritynews.com — все найдены WebSearch, содержимое сайтов не
открывалось напрямую, но список вредоносного ПО и меры Anthropic совпадают дословно во всех).
Путь применён: F-01 путь 1 для обоих первоисточников — оба открыты целиком напрямую.

Факты:
- Anthropic разослала предупреждения части пользователей Claude о краже данных для входа.
- Злоумышленники использовали инфостилеры, ворующие сохранённые пароли, cookies и другие
  учётные данные с заражённых устройств; украденные cookies сессии позволяют входить в
  аккаунт без пароля и без повторного прохождения двухфакторной аутентификации.
- Названные семейства вредоносного ПО на Windows: Vidar, LummaC2, StealC, RedLine, Acreed.
- На macOS: Atomic Stealer.
- Меры Anthropic: завершила активные сессии скомпрометированных аккаунтов, удалила
  сохранённые способы оплаты, вернула деньги за несанкционированные списания.
- Рекомендация Anthropic пострадавшим: удалить вредоносную программу с устройства и сменить
  учётные данные (выход из Claude сам вредонос не убирает).
- Отдельный случай: сооснователь инвестплатформы Refi Hub Нума Лунах (в статье — Нума Лунах)
  попросил Claude найти приложение для расшифровки аудио; чат-бот дал ссылку на установку,
  которая вела на сайт-клон, распространяющий вредоносное ПО.
- После переустановки Windows в резервной копии данных обнаружился заражённый файл SKILL.md —
  личный «навык» для Claude Code, замаскированный под стилизацию ответов ИИ, который при
  каждой загрузке файла Claude'ом незаметно переустанавливал вредоносное ПО и воровал учётные
  данные.
- По словам Лунаха, чувствительные данные не утекли; цель подобных атак — API-ключи, учётные
  данные разработчиков и личные данные для перепродажи.
- Обе новости опубликованы 31.08.2026.

Названия в тексте: Claude, Anthropic, Claude Code — все присутствуют выше.

## Пост 2. Instagram ограничивает охват недекларированных ИИ-персонажей

Первоисточник: https://techcrunch.com/2026/08/31/instagram-puts-new-limits-on-undisclosed-ai-profiles/
(открыт целиком, WebFetch)
Путь применён: F-01 путь 1 — первоисточник открыт целиком.

Факты:
- Meta (Instagram) вводит ограничения на профили с ИИ-персонажами (ботами), которые не
  раскрывают пользователям свою природу.
- Авторам таких аккаунтов нужно применить статус профиля «AI-generated profile», чтобы
  пользователи понимали, что это не реальный человек.
- Если статус не проставлен, Instagram снижает охват (reach) такого аккаунта.
- Причина, названная Instagram: пользователи не хотят натыкаться на страницы, похожие на
  профили реальных людей, и обнаруживать позже, что персонаж создан ИИ.
- Если автор считает, что ограничение применено ошибочно, можно подать апелляцию через панель
  Account Status.
- Дата публикации: 31.08.2026, автор — Lauren Forristal.

Названия в тексте: Instagram, Meta — присутствуют выше.

## Пост 3. Circleback добавил бесплатный тариф

Первоисточник: https://techcrunch.com/2026/08/31/meeting-notetaker-circleback-adds-a-free-tier-to-attract-more-customers/
(открыт целиком, WebFetch)
Путь применён: F-01 путь 1 — первоисточник открыт целиком.

Факты:
- Circleback — сервис автоматических заметок со встреч, конкурирует с Granola, Read AI,
  Fireflies.
- До этого обновления бесплатного тарифа не было, платные тарифы начинались от $20,83/мес.
- Новый бесплатный тариф: безлимитная транскрибация встреч, доступ к истории только за
  последние 30 дней, мобильные приложения и приложение для Apple Watch, ИИ-поиск по
  транскриптам, интеграции с Linear и Slack.
- Платные тарифы теперь начинаются от $15/мес при годовой оплате (раньше — от $20,83/мес);
  платный план даёт неограниченную историю встреч, все интеграции и полный доступ к API/MCP.
- Компания сообщает, что прибыльна; годовой доход на сотрудника больше $1 млн при штате
  около 8 человек; в 2024 году привлекла $2,5 млн инвестиций.
- В статье нет информации о доступности оплаты из России — прямо не сказано, что работает,
  прямо не сказано, что не работает.
- Дата публикации: 31.08.2026.

Названия в тексте: Circleback — присутствует выше. Granola/Read AI/Fireflies упомянуты только
как рынок конкурентов, в пост не идут (не нужны по теме).

## Пост 4. Gemini Enterprise: оплата по факту использования и лимиты трат

Первоисточник: https://www.axios.com/2026/08/26/exclusive-google-targets-ai-sticker-shock-with-new-tools
(WebFetch на axios.com заблокирован — EGRESS_BLOCKED)
Подтверждение: факты собраны перекрёстно WebSearch по пяти независимым публикациям —
itbrief.co.uk, techrepublic.com, vktr.com, eweek.com, shopifreaks.com (домены самих статей
не открывались напрямую, WebFetch на них не пробовался — заблокированные ранее в этом же
прогоне ciodive.com и cryptobriefing.com показали, что профиль блокировки у таких изданий
общий; факты сверены по совпадению формулировок в выдаче WebSearch по двум независимым
запросам).
Путь применён: F-01 путь 2 — первоисточник закрыт для автоматических запросов, факты собраны
перекрёстным поиском.

Факты:
- Google добавил для Gemini Enterprise оплату по факту использования (pay-as-you-go) —
  без базовой абонентской платы и без предоплаты, по стандартным ставкам API за
  потреблённые вычисления и токены.
- Тариф pay-as-you-go доступен организациям от 20 мест, постепенно раскатывается на
  ограниченную группу клиентов.
- Лимиты трат: жёсткий месячный лимит на проект, автоматические оповещения по email при
  достижении 50%, 80% и 100% бюджета, автопауза вызовов агентского API при достижении лимита;
  администратор может возобновить работу вручную или разрешить перерасход.
- Flexible Savings Plans — скидка за обязательство по объёму трат: 10% при годовом
  обязательстве, 20% при трёхлетнем; доступны сразу для самостоятельных клиентов и для тех,
  кто уже на корпоративном контракте.
- F-06: цифра «скидка до 50% за перенос задач в офф-пик», встретившаяся в первом заходе поиска,
  не подтвердилась во втором независимом заходе (там фигурируют только 10%/20% Flexible Savings
  Plans) — в пост не идёт вовсе.
- Дата анонса: 26.08.2026.

Названия в тексте: Google, Gemini Enterprise — присутствуют выше.
