# Проверка фактов за 2026-08-15

## Тема 1. Битрикс24 Коворк/Код: AI-агент вместо разработчика для внутренних задач

- Первоисточник: https://www.bitrix24.ru/journal/vaybkod-bitrix24-gayd-novichkov/ — открыт
  целиком через WebFetch (bitrix24.ru в allowlist).
- Подтверждение: https://www.bitrix24.ru/journal/novyy-bitriks24-vaybkod/ — открыт целиком,
  тот же домен, независимая статья с теми же фактами про Коворк/Код и AI-агента Hermes.
  Прямые продуктовые страницы cowork.bitrix24.ru и helpdesk.bitrix24.ru закрыты allowlist
  (EGRESS_BLOCKED), в проверку не вошли.
- Коворк/Код — десктоп-приложение с AI-агентом для macOS и Windows. Выполняет задачи в
  портале Битрикс24 и на компьютере пользователя: работает с файлами, ставит задачи,
  собирает аналитику, пишет и публикует готовые приложения по текстовому описанию задачи.
- Единая точка доступа к данным портала: сделки, задачи, чаты, файлы, календарь, телефония —
  около 40 сущностей Битрикс24.
- Серверы Black Hole: облачные серверы без публичного IP и открытых портов, «полностью
  невидимые из интернета»; данные клиентов третьим лицам не передаются.
- Оплата: нужна подписка «BitrixGPT + Маркетплейс». Внутренняя валюта — вайбы: серверы стоят
  от 300 до 8000 руб/месяц, AI-поиск — 2-5 вайбов за запрос, хранилище — около 2 вайбов за
  ГБ/месяц. Пакеты вайбов: Стартовый (1000), Командный (5000), Профи (25000). У Коворк/Код
  отдельная подписка с уровнями Free, Start, Pro, Max — конкретные цены по уровням в
  источниках не названы, в пост не идут.
- AI-агент Hermes: встроенный чат-бот в мессенджере портала, работает на обычном языке
  («найди сделки по клиенту за март», «поставь задачу»), помнит контекст.
- Числа в посте: «около 40 сущностей», «от 300 до 8000 руб/месяц» — оба подтверждены в обоих
  источниках дословно.

## Тема 2. Циан: интервью ИТ-директора про внедрение генеративного ИИ

- Первоисточник: https://www.cnews.ru/reviews/tehnologii_iskusstvennogo_intellekta_1/interviews/maksim_radyukov
  — открыт целиком через WebFetch (cnews.ru в allowlist).
- Дата публикации: 12 августа 2026, часть обзора «Технологии искусственного интеллекта 2026».
- Циан-помощник: потребительский продукт, персонализирует поиск жилья по текстовым запросам;
  с момента запуска с сервисом взаимодействовало более 7 млн человек, около 70% просматривают
  все рекомендации.
- GPT Gateway: внутренний единый контур управления моделями компании, обрабатывает около
  300 тыс. запросов в сутки. Подход гибридный: внешние API для скорости, локальные модели —
  для конфиденциальных данных, запрет передавать персональные данные внешним моделям.
- Цитата Радюкова: 95% компаний, попробовавших внедрить ИИ, не получили измеримого
  финансового эффекта — нужен чёткий расчёт ROI. Отдельно отмечено: без подготовки команды
  прямое внедрение снижало производительность, обучение сотрудников критично.
- Результаты Циан: поисковая выдача ускорена на 13%, около 35% кода в день пишет нейросеть
  в разработке, чистота модерации объявлений 99%.
- Второй источник не потребовался (F-01): первоисточник открыт целиком напрямую.
- Числа в посте: «7 млн», «300 тыс.», «95%» — все дословно совпадают с первоисточником.

## Тема 4. Notion: карточка сравнения моделей ИИ вместо списка названий

- Первоисточник: https://www.notion.com/releases/2026-08-14 — открыт целиком через WebFetch
  (notion.com в allowlist).
- Дата: 14 августа 2026.
- Суть: список моделей в Notion AI заменён на короткий список моделей со «scorecard» —
  карточкой сравнения по трём параметрам: скорость, интеллектуальность, стоимость. Можно
  закрепить избранные модели для быстрого доступа («Pin your favorites»). Появилась
  возможность повышать уровень усилий (effort) модели, когда нужен более обстоятельный ответ.
- Конкретные названия моделей, различия по тарифным планам и ограничения в источнике не
  указаны — в пост эти детали не идут.
- Оплата: подписку Notion из России напрямую российской картой не оплатить (Notion выставляет
  счёт в долларах, карты российских банков не принимаются) — подтверждено перекрёстно
  несколькими независимыми русскоязычными разборами способов оплаты (vc.ru, DTF).
- Второй источник для основного факта не потребовался (F-01): первоисточник открыт целиком.
- Числа в посте: числовых значений нет — только качественное описание («три параметра»),
  которое дословно совпадает с источником.
