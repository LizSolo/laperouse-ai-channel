# RULES.md — проверяемые правила

Единственный файл с правилами. Голос и интонация — проза в `STYLE.md` и `EXAMPLES.md`:
чек-листом их не задать. Здесь только то, на что можно ответить да/нет.

**Как пользоваться.** Сначала `python pipeline/lint.py` — он закрывает правила с пометкой
*(скрипт)* и пишет по ним `pipeline/lint.md`. Гонять до кода возврата 0: тот же скрипт зовёт
`send_drafts.py`, и пост с непочиненным «нет» в группу не уйдёт. Остальные правила пройти
самому и записать в `pipeline/selfcheck.md` строкой `ID: да|нет — цитата из поста`. Каждое
«нет» исправить и проверить заново. Ответ «да» без цитаты для правил, где цитата возможна,
считается непройденной проверкой.

**Почему разделение.** Проставленное себе «да» — утверждение об успехе, а не доказательство:
за 07.08 и 08.08 два «да» из трёх по F-01 стояли при неоткрытом источнике. Что проверяется
поиском по строке, проверяет строка, а не впечатление.

**Формат правила.** Одно предложение, проверяемое условие и ничего больше. Пример внутри
правила допустим, только когда он определяет условие («от фрилансеров до корпораций»).
Истории, дат и объяснений «почему так» здесь нет: они в `NOTES.md`, раздел
«Почему правила такие», по тому же ID. Правило, которое не влезло в предложение, —
это два правила.

**Пять правил судейские: T-01, X-02, X-09, X-11, X-18.** Счётом их не проверить, сверяйся
с `EXAMPLES.md`. В selfcheck по ним обязательна цитата и одна строка рассуждения.

**Пороги измерены по пяти постам автора** (`EXAMPLES.md`, варианты автора), последний
пересчёт 08.08. Появится новая пара — пересчитать скриптом, а не защищать старые числа.

## ТЕМА (T) — проверяется до написания

- **T-01** *(судейское)* Тема меняет конкретное действие в работе владельца бизнеса вне AI-ниши, и это действие сформулировано одной строкой в `pipeline/funnel.md` и в selfcheck.
- **T-02** Темы нет ни в одной строке `PUBLISHED.md`, независимо от статуса.
- **T-03** Пост не держится на сумме раунда, оценке компании или росте выручки, и эти числа в тексте не упоминаются.
- **T-04** Тема не про безопасность самих ИИ-лабораторий: побеги агентов, взломы, исследования выравнивания.
- **T-05** Основной сервис поста доступен из России: регистрация проходит, доступ по стране не заблокирован. Оплата российской картой не обязательна, но её отсутствие названо в посте прямым текстом. Исключение — Claude и ChatGPT.
- **T-06** *(скрипт: охват)* Обойдены ровно пять категорий источников из `prompts/author.md`, раздел 2.2, шестого захода в `pipeline/funnel.md` нет, и по каждой категории там стоит либо кандидат, либо «пусто» с названием проверенной страницы. Скрипт считает категории и требует у каждой кандидата или «пусто»; названа ли реально открытая страница — проверяется глазами.
- **T-07** Источник опубликован больше 72 часов назад → давность названа в первых двух предложениях либо пост написан вне привязки ко времени; слов «вышло», «на днях», «недавно» в нём нет.
- **T-08** Про одну компанию не больше одного поста в прогоне, и тема не совпадает по компании с двумя последними записями `PUBLISHED.md`, не считая записей этого прогона.
- **T-09** *(скрипт: вердикты)* `pipeline/funnel.md` перезаписан на сегодня: результат по каждой категории и строка `тема — категория — взят | отсеян по <ID>` на каждого кандидата, включая отсеянных до проверки фактов. Вердикта ровно два. Кандидат, прошедший все T и F, идёт в пост.
- **T-10** Тема, прошедшая отбор, но не проверенная из-за нехватки времени, записана в `pipeline/funnel.md` в раздел «Не проверено, взять завтра» с источником и строкой по T-01; вчерашний раздел разобран до начала нового поиска.
- **T-11** Источник опубликован не раньше чем за 30 дней до даты прогона.
- **T-12** Пока в `prompts/author.md` включён режим отбора, кандидата отсеивают только T-01, T-02 и T-11, а T-03, T-04, T-05 и T-08 не отсеивают: у кандидата стоит вердикт «взят» с их ID в квадратных скобках, и по нему пишется пост.
- **T-13** *(скрипт: метка категории)* При включённом режиме отбора последняя строка каждого поста — `— кат. N · <пометки или «пометок нет»>` под подписью.
- **T-14** *(скрипт: счёт взятых)* При включённом режиме отбора постов в `DRAFTS.md` плюс тем в разделе «Не проверено, взять завтра» ровно столько, сколько в `pipeline/funnel.md` кандидатов с вердиктом «взят».
- **T-15** При включённом режиме отбора `pipeline/selfcheck.md` содержит только пять судейских правил на пост — T-01, X-02, X-09, X-11, X-18; остальные закрывает скрипт.

## ФАКТЫ (F)

- **F-01** Первоисточник открыт целиком, либо, если он закрыт для автоматических запросов, факт совпадает дословно не меньше чем в двух независимых публикациях. В selfcheck пишется, какой из двух путей применён.
- **F-02** `pipeline/verified.md` перезаписан на сегодня: по каждой теме URL первоисточника, URL подтверждения, список фактов.
- **F-03** Каждое название продукта, сервиса и компании из поста присутствует в `verified.md`; обобщение без бренда допустимо, отсутствующее в файле название — нет.
- **F-04** *(скрипт: сверка чисел)* Каждое число из поста присутствует в `verified.md`.
- **F-05** Для каждой цены указано, помесячная она или годовая, и это совпадает с тарифной страницей; вычислять цену самостоятельно запрещено.
- **F-06** Источники расходятся в цифре → цифра не пишется вовсе.
- **F-07** URL первоисточника в `verified.md` открыт или найден поиском. Собирать адрес по шаблону запрещено: не открылся — ставится ссылка на подтверждающую публикацию, а не догадка.

## ТЕКСТ (X)

- **X-02** *(судейское)* Первое предложение говорит, что меняется для читателя, а не какой продукт вышел и с какими характеристиками.
- **X-03** Есть хотя бы одно предложение с личной оценкой или рекомендацией. Список не закрытый, годится любая своя формулировка; для образца: «мне кажется», «стоит посмотреть», «сейчас хороший момент», «не стоит».
- **X-04** *(скрипт)* Абзац не длиннее 3 предложений, между абзацами пустая строка.
- **X-05** Развёрнутых сценариев («Представьте, что вам нужно…») не больше одного на пост.
- **X-06** Перечисление из трёх и более однородных элементов оформлено списком, а не запятыми внутри предложения.
- **X-07** Последний абзац перед подписью содержит конкретное действие читателя, и это действие не повторяет сказанное выше другими словами. Глагол любой, для образца: попробуйте, посмотрите, обсудите, протестируйте.
- **X-08** *(скрипт)* Длина поста 900–1800 знаков без учёта HTML-тегов; число написано в selfcheck. Пост длиннее 1800 сокращается, а не публикуется.
- **X-09** *(судейское)* В посте одна мысль; второй сюжет, который тянет на отдельный пост, вынесен или убран.
- **X-10** Западный релиз занимает не больше двух предложений, остальной пост — про то, чем читатель может воспользоваться здесь.
- **X-11** *(судейское)* Нет трёх подряд предложений одинаковой длины и конструкции.
- **X-12** *(скрипт)* Первая строка не длиннее 150 знаков и понятна в отрыве от остального поста.
- **X-13** *(скрипт)* Обращение к читателю на «вы» есть в тексте поста.
- **X-14** Не больше одного отглагольного существительного на абзац, страдательный залог переписан активным: «настройка позволяет осуществлять обработку заявок» → «настроил, и заявки разбираются сами».
- **X-15** В selfcheck одним предложением сформулировано, что читатель сделает после поста; «узнает», «поймёт», «будет в курсе» не годятся.
- **X-16** Черновик сокращён отдельным проходом. Порядок удаления: второй сюжет → пояснение к известному → вводный абзац → половина пунктов списка → второй пример к той же мысли. Личная оценка (X-03) и финальное действие (X-07) удаляются последними.
- **X-17** На каждый объект в посте не больше двух обозначений: собственное имя плюс одно родовое слово.
- **X-18** *(судейское)* Третий однородный элемент, который ничего не добавляет к первым двум, удаляется: «быстро, дёшево и надёжно» → «быстро и дёшево».

## ФОРМАТ (M)

- **M-01** *(скрипт: эмодзи и заголовок)* Первая строка — обычное предложение с эмодзи в конце, а не заголовок-ярлык. Так нельзя: «<b>У ChatGPT в PowerPoint завтра заканчивается бесплатный период</b> ⏳». Так надо: «Скорее всего, кто-то из ваших сотрудников уже использует ChatGPT, Claude или Gemini в работе. 🤖».
- **M-02** *(скрипт)* `<b>жирным</b>` выделяются только ключевые термины и названия продуктов: хотя бы один фрагмент в посте, не больше одного на абзац, никогда целое предложение и никогда вся первая строка.
- **M-03** *(скрипт)* Меток-ярлыков «Нюанс», «Проверить просто», «Важно» в тексте нет; оговорка пишется обычным предложением.
- **M-04** *(скрипт)* Ссылка оформлена как `<a href="URL">Источник</a>`; сырого URL и заголовка статьи в тексте нет.
- **M-05** *(скрипт)* Последняя строка поста — `#ЛизаСоло 👩‍💻`.
- **M-06** `DRAFTS.md` перезаписан целиком, а не дополнен.
- **M-07** *(скрипт)* Блоков в тройных обратных кавычках ровно столько, сколько постов, других таких блоков в файле нет.
- **M-08** *(скрипт)* Внутри блока только готовый текст поста; пояснения и строка `Источник: URL` — вне блока.
- **M-09** *(скрипт)* Строка `Скрипт: … код N` в `pipeline/selfcheck.md` называет код, который `lint.py` правда вернул на этом прогоне.

## ЗАПРЕТЫ (Z) — ищутся по строке, без интерпретации

- **Z-01** *(скрипт)* Нет тире с пробелами как связки между частями предложения; в диапазонах чисел и в прямой речи допустимо.
- **Z-02** *(скрипт)* Нет слов: «именно», «таким образом», «в итоге», «итак», «подводя итог».
- **Z-03** *(скрипт)* Нет конструкции «не X, а Y».
- **Z-04** *(скрипт)* «Поэтому» не открывает финальный абзац.
- **Z-05** *(скрипт)* Нет вопросов-клише: «а что если», «задумывались ли вы», «знакомо?». Сценарий «Представьте, что…» разрешён.
- **Z-06** *(скрипт)* Нет инфобизнес-языка: «давайте разберёмся», «сегодня хочу поделиться», «это изменит ваш бизнес», «мало кто понимает», «секрет успеха», «невероятный инсайт», «все должны использовать ИИ».
- **Z-07** В конце нет вывода-саммари, пересказывающего сказанное выше.
- **Z-08** *(скрипт)* Факт или цифра не подпираются безымянной группой: «эксперты считают», «аналитики называют», «исследования показывают», «как известно». Источник назван по имени и лежит в `verified.md`, либо утверждение снимается. Проверяется только подкрепление факта: «задача, о которой многие забывают» — обычная речь.
- **Z-09** *(скрипт)* Нет раздувания значимости: «знаменует», «переломный момент», «новая эра», «меняет правила игры», «беспрецедентный», «настоящий прорыв», «революция в», «нельзя недооценивать».
- **Z-10** *(скрипт)* Нет диапазона «от … до …» с категориями на концах: «от фрилансеров до корпораций». Диапазон чисел разрешён.
- **Z-11** Запреты Z действуют, даже когда оборот встречается в опубликованных постах автора.

## Образец `pipeline/selfcheck.md`

Только правила **без** пометки *(скрипт)*: остальные лежат в `pipeline/lint.md`, и
переписывать их сюда не надо.

```
# Самопроверка за 2026-08-05
Скрипт: pipeline/lint.py, код 0, отчёт в pipeline/lint.md

## Пост 1. Тема
T-01: да — «что делать с сотрудниками, которые носят данные в чат-боты» — судейское: действие названо глаголом, читатель вне AI-ниши
T-03: да — раунда в тексте нет
X-03: нет → ИСПРАВЛЕНО, добавлено «сейчас хороший момент их обсудить»
X-07: да — «Договоритесь, какие сервисы можно использовать»
X-15: да — читатель соберёт команду и договорится о списке разрешённых сервисов
```

Правила, к которым цитата неприменима (T-06, F-01, M-06), отмечаются просто «да» или «нет».
По пяти судейским (T-01, X-02, X-09, X-11, X-18) кроме цитаты нужна строка рассуждения.

## Образец `pipeline/funnel.md`

Перезаписывается каждый прогон, пишется по ходу отбора, а не задним числом.

В «Охвате источников» строка на каждую из пяти категорий раздела 2.2 `prompts/author.md`,
в том же порядке и с теми же названиями. Сам список категорий здесь не повторяется
намеренно: он живёт в одном месте, и это `prompts/author.md`.

```
# Воронка за 2026-08-08

## Охват источников
<пять строк, по одной на категорию, в одной из двух форм:>
2. <название категории> — docs.claude.com, notion.com/releases: 1 кандидат
3. <название категории> — techcrunch.com, theverge.com: пусто, только раунды (пусто 2 прогон подряд)

## Кандидаты
- Ozon, ИИ-ассистент для покупателей — кат. 1 — взят — читатель проверит заполненность карточек
- Sonnet 5, конец промо-цены — кат. 4 — отсеян по T-08 (Anthropic был 06.08)
- Раунд Emergent $1.5 млрд — кат. 3 — отсеян по T-03
- Notion Custom Agents — кат. 2 — отсеян по T-02 (отправлено 06.08)

## Не проверено, взять завтра
- Bitrix24, ИИ-скоринг сделок — кат. 2 — https://... — читатель включит скоринг в своей воронке

## Домены, закрытые allowlist
- пусто

Итог: кандидатов 6, взято 1, до поста дошло 1, отложено 1.
```
